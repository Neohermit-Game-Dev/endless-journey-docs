AmmoManager

This item only works when running on the server. Server

Authoritative, in-memory (session-only) per-player ammo pool keyed by ammo type (see Configs/AmmoConfig). Guns draw from it on reload; crafting adds to it. Mirrors the CoinManager shape but WITHOUT persistence. Every mutation fires AmmoPoolSync to the owning client. Call Initialize() once from a server bootstrap; call EnsureStarting(player) on each spawn — it seeds the pool on the first spawn only (it persists across death) and re-syncs it to the client.

EnsureStarting​

</>
AmmoManager.EnsureStarting(player: Player) → ()

Seed each ammo type to its Starting amount on the player's FIRST spawn only; existing pools persist across death (so dying never refills reserve ammo). Always re-syncs every type to the owning client (the HUD is rebuilt on respawn). Cleared only on leave (Clear).
