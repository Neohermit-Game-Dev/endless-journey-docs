Biomes

Each biome has its own look (sky, Lighting, haze scenery) and ambience. The look is data in Studio, under ReplicatedStorage.Biome. When the server changes workspace.CurrentBiome (inside the wormhole, see Jump Drive), every client swaps the look and the ambience beds. Biome music is separate: see Sound.

At a glance​

LayerFileRole
Sharedsrc/ReplicatedStorage/SharedModules/BiomeVisuals.luauApply(biomeId): swaps Lighting values, Lighting children and workspace.BiomeScenery
Clientsrc/StarterPlayer/StarterPlayerScripts/BiomeController.client.luauCalls BiomeVisuals.Apply and SoundManager.SetAmbience at start and on every CurrentBiome change
Configsrc/ReplicatedStorage/SharedModules/Configs/SoundConfig.luauAmbience.Beds (bed ids), Ambience.PerBiome (biome id → bed names), Ambience.BiomeFade (3 s)
StudioReplicatedStorage.Biome.<Id>One folder per biome (layout below)

Packets / Signals: none. The biome travels as the CurrentBiome workspace attribute (JumpDriveConfig.BIOME_ATTRIBUTE).

Biome folder layout​

ReplicatedStorage.Biome.<Id> (Folder):

  • Attributes — Lighting property values. Every biome folder carries the same full set, the 15 that Biome.Normal has: Ambient, OutdoorAmbient, Brightness, ClockTime, ColorShift_Top, ColorShift_Bottom, EnvironmentDiffuseScale, EnvironmentSpecularScale, ExposureCompensation, GeographicLatitude, GlobalShadows, ShadowSoftness, FogColor, FogEnd, FogStart. A missing attribute keeps the previous biome's value.
  • Lighting/ — Sky, Atmosphere and post effects. Apply clones them into Lighting and tags each clone BiomeVisual.
  • Scenery/ — client-only scenery (haze particle layers). Apply replaces workspace.BiomeScenery with a clone.

Biome.Skybox/ and Biome.Ambient/ are the artist's asset library. Code does not read them.

How Apply works​

  1. Destroy Lighting children tagged BiomeVisual, and any Sky or Atmosphere (Lighting uses only one of each). Untagged post effects stay, so the jump transition's JumpColorCorrection and JumpBlur are never touched.
  2. Write the folder's attributes to Lighting.
  3. Clone Lighting/ children into Lighting, tagged.
  4. Replace workspace.BiomeScenery with a clone of Scenery/, or remove it when the biome has none.

A biome with no folder (Ice, Void and Storm today) falls back to Normal, with one warning per id.

Studio preview​

Run in the command bar:

require(game.ReplicatedStorage.SharedModules.BiomeVisuals).Apply("Volcano")
require(game.ReplicatedStorage.SharedModules.BiomeVisuals).Apply("Normal")

Switch back to Normal before you save the place. Otherwise the preview look saves into Lighting and Workspace. The command bar caches require: after a Rojo edit to BiomeVisuals, use loadstring(game.ReplicatedStorage.SharedModules.BiomeVisuals.Source)().Apply(...).

Volcano​

  • Sky: Mecury Skybox copy, no sun, moon or stars. Atmosphere Haze 1.95, Density 0.3: Haze mutes the red sky but also fogs objects, so Density is lowered to keep train-level visibility. Change the two together.
  • Scenery (all drift +X with the world scroll; the train is static and faces −X): HazeDeep (thick smoke below the train), HazeWisps (thin, just under the train), HazeMid (slight dark band at train height that joins the sky haze to the haze below), HazeHigh (smoke ceiling at y ≈ 450 that darkens the sky overhead; ~1400 large particles — check its cost on a low-end phone).
  • Ambience: LavaBubbling + LavaRumble.
  • Hazards: front rocks and eruptions, see Rock Hazards.

Adding a biome look​

  1. Duplicate Biome.Normal, rename it to the biome id (an entry of JumpDriveConfig.Biomes), and edit its attributes and Lighting/ children.
  2. Add Scenery/ if the biome needs haze layers. Keep particles away from the deck: large particles reach far outside their emitter box.
  3. Add its beds to SoundConfig.Ambience.Beds and Ambience.PerBiome.
  4. Preview with Apply, then switch back to Normal and save.
