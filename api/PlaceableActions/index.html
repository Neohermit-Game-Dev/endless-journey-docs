PlaceableActions

Client-only helper that wires a placed object's GUI buttons (Stash / Move) to the corresponding server packets, and handles the broadcast poof visual + sound that plays when any player stashes or moves a placeable.

Usage

local PlaceableActions = require(SharedModules.PlaceableActions)

-- Wire buttons when the GUI opens:
local binding = PlaceableActions.bind(placedModel, guiRoot)

-- Clean up when the GUI closes:
binding:Unbind()

guiRoot must contain ImageButtons named MoveButton and/or StashButton somewhere in its descendant tree. A missing button logs a warning but does not error.

The poof handler (BroadcastPlaceablePoof packet listener) is registered automatically on the client when the module loads; no manual init is needed.

model: Model,--

The placed object whose actions are being bound.

gui: Instance--

Root GUI instance containing MoveButton and/or StashButton.

) → Binding--

Binding handle; call :Unbind() to clean up.

Wires MoveButton and StashButton inside gui to their respective server packets (ReqMovePlaceable / ReqStashPlaceable) for the given model.

Button clicks are debounced: only one request may be in-flight at a time. When the server succeeds, the corresponding signal is fired:

  • Move success → Signals.OnPlaceableMoved
  • Stash success → Signals.OnPlaceableStashed

The returned Binding has a single method:

binding:Unbind() — disconnects all button listeners and suppresses any pending success signal. Call this when the GUI closes. Safe to call multiple times (subsequent calls are no-ops).

Model destruction

When model is destroyed by the server (which happens on success before the response arrives), button listeners are disconnected automatically. The in-flight success-signal path is preserved so callers still receive the OnPlaceableMoved / OnPlaceableStashed event.
