EnergyToolHelper

This item only works when running on the server. Server

Shared server-side helpers for identifying and consuming "Energy" Tool items from a player's backpack/character. Used by both the train fuel and train shield recharge flows so the detection/consumption logic lives in one place.

An Energy tool is a Tool whose PrimaryPart carries attribute Type == "Energy" and a numeric Tier (1..5).

Functions​

GetEnergyTier​

</>
EnergyToolHelper.GetEnergyTier(tool: Instance) → number?

Returns the numeric Tier of an Energy tool, or nil if tool is not a valid Energy tool.

GatherEnergyTools​

</>
EnergyToolHelper.GatherEnergyTools(player: Player) → {Tool}

Collects every Energy tool the player currently holds — both in their Backpack and the one (if any) equipped on their character.

ConsumeTool​

</>
EnergyToolHelper.ConsumeTool(
player: Player,
tool: Tool
) → ()

Consumes a single Energy tool: if it is the equipped tool, unequips it first (so the character isn't left holding a destroyed handle), then destroys it.
