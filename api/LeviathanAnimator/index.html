LeviathanAnimator

Animation for the Leviathan boss (client side). The model is skinned MeshParts with one bone tree under its PrimaryPart (the root part). Every frame the spine bones and the Head bone are laid along a moving path (each wanted world pose is written as the bone's Transform) and the parts move rigidly with the root. The jaw, wings, fins and the bones under the head play the Blender clips in LeviathanAnimConfig.Clips (a wing loop per move, a jaw one-shot, a head sway).

Moves and their timing live in LeviathanAnimConfig.

local anim = LeviathanAnimator.new(workspace.Leviathan)
anim.OnEvent = function(name) print(name) end -- "Impact", "LaserFire"
local seconds = anim:Play("SlamBack", trainCFrame, trainLength)

PlaySegment​

</>
LeviathanAnimator.PlaySegment(
self: LeviathanAnimator,
segment: Segment
) → number

Plays a segment on server time: pose time = workspace:GetServerTimeNow() - segment.Start, clamped to the move's length, so a client that joins mid-move lands where the move really is. Stops any move in progress. Fires OnEvent for every event whose time passes (events already past at the start are skipped). Segment rifts are added to Rifts. Returns the move length in seconds; the model keeps the last pose when it ends.

Play​

</>
LeviathanAnimator.Play(
self: LeviathanAnimator,
moveName: string,
origin: CFrame,
trainLength: number
) → number

Plays a move from LeviathanAnimConfig around origin (the train centre: -X = heading, +Y = up). trainLength (studs along X) sets the laser sweep. Builds a segment that starts now and plays it (see PlaySegment). Kept for the Studio preview tools; the fight sends segments from the server.
