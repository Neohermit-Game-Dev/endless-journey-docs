Threat Timer

A server-authoritative countdown to the arrival of the Leviathan, the boss that hunts the train through the void. The countdown starts when the train first moves and resets on every jump arrival, so jumping is how the party escapes it. Running out of fuel makes it count down faster. When it reaches 0, an omen warning plays, and the boss arrives after a short delay. The boss itself is not built yet: this system only fires the seam signal it will use.

How it works​

Phases​

stateDiagram-v2
    [*] --> Counting
    Counting --> Imminent: remaining reaches 0
    Imminent --> Arrived: SPAWN_DELAY elapsed (OnThreatArrived fires)
    Counting --> Counting: jump arrival (reset to ARRIVAL_SECONDS)
    Imminent --> Counting: jump arrival
    Arrived --> Counting: jump arrival
PhaseMeaning
CountingThe countdown runs from ARRIVAL_SECONDS (900 s)
ImminentThe countdown hit 0. The omen toast shows, and SPAWN_DELAY (30 s) runs in real time
ArrivedSignals.OnThreatArrived fired once. Holds until the next jump arrival

Speed​

The countdown speed is a pure function of the current state (speedFor):

Condition (first match wins)Speed
Train not started yet, a jump is active, game over, or phase Arrived0 (paused)
Phase Imminent1
Train stalled (OnTrainFuelStateChanged stalled = true)STALLED_SPEED (4) × Bait Buoy
Otherwise1 × Bait Buoy

Imminent ignores fuel on purpose: the 30 s is the party's last warning, and refuelling during it neither shortens nor lengthens it. An Emergency Generator coast does not speed up the countdown — the signal reports a coast as empty = true, stalled = false, and the timer reads only stalled. The client shows a "running on fumes" toast instead (see Client).

Bait Buoy (party shop perk, PartyPerkBuffs.ThreatSlowdown 0.10): the Counting speed is PerkBuffRead.Reduce(speed, ThreatSlowdown) (× 0.9, never below 10%). Imminent stays real time. A change of the attribute calls commit, so remaining is snapshot under the old speed. Clients read the replicated speed from ThreatStateSync, so the clocks need no change.

Braking does not pause the countdown. A braked train burns no fuel (Train Fuel); the Leviathan clock is the cost of waiting.

Algebraic model​

Like TrainFuelManager, there is no per-frame loop. Every input (train start, fuel state, jump phase, game over) calls commit(), which:

  1. snapshots remaining -= speed * (now - lastEventTime) under the old speed,
  2. picks the new speed with speedFor,
  3. bumps a nonce and, if the speed is above 0, schedules task.delay(remaining / speed) to advance the phase — a stale callback whose nonce no longer matches does nothing,
  4. broadcasts ThreatStateSync(phase, remaining, speed, serverTime).

Entering a new phase (enterPhase) moves lastEventTime to now before committing, so the new phase's budget is not reduced by time spent in the old one. Time lost while stalled stays lost: refuelling only returns the speed to 1.

Clients compute the live countdown as max(0, remaining - speed * (GetServerTimeNow() - serverTime)), the same extrapolation TrainStateSync uses.

Jump reset​

OnJumpPhaseChanged pauses the countdown while JumpDriveConfig.IsJumpActive(phase) is true. On the arrival edge (active → inactive) it resets to a full Counting, whatever the phase was. If the train is still stalled on arrival, the new cycle starts at STALLED_SPEED.

Client​

  • TrainClient shows two fuel toasts from TrainStateSync edges: FUMES_MESSAGE (warn) when coastEndsAt goes from 0 to a value above 0, and FUEL_OUT_MESSAGE (alert) when isStalled goes from false to true. They follow the stall flag, not the countdown speed, so the fuel-out toast also shows during Imminent.
  • ThreatController shows OMEN_MESSAGE (alert) once when the phase becomes Imminent.
  • MusicDirector plays Pursuit while the train is stalled or the phase is past Counting (priority Jump > Combat > Pursuit > LowFuel > Normal). The Pursuit playlist has no tracks until asset ids are added to SoundConfig.

A player who joins while one of these states is already active gets that toast once, from the join snapshot. This is intentional: they need to know.

Seams​

  • Leviathan boss. Signals.OnThreatArrived is where the future boss spec spawns the boss. The boss must leave on the OnJumpPhaseChanged arrival edge, matching the reset above. It hits the train with TrainShieldManager.ApplyDamage(amount, ThreatConfig.BOSS_DAMAGE_SOURCE); see Train Shield — Hull.
  • Game-over cutscene. Reads the TrainGameOverReason from Signals.OnTrainGameOver.

Config surface​

ThreatConfig timer fields: ARRIVAL_SECONDS (900), STALLED_SPEED (4), SPAWN_DELAY (30), Phase. Toasts: NOTIF_TYPE, FUMES_NOTIF_TYPE, NOTIF_DURATION, FUMES_MESSAGE, FUEL_OUT_MESSAGE, OMEN_MESSAGE. Hull fields are documented under Train Shield — Hull.
