Update Build Mode UI/UX

Goal: Change build-mode icon assets, ghost visuals, grid overlay appearance, or the button-to-signal mapping in BuildModeGuiController.

Steps​

  1. Open the placement config. Visual and icon settings live in src/ReplicatedStorage/SharedModules/Configs/PlacementConfig.luau.

  2. Replace icon asset IDs. The Icons table holds one entry per toolbar button:

    Icons = {
        GridOn       = "rbxassetid://118749020984103",
        GridOff      = "rbxassetid://132920215751528",
        GhostUnlocked = "rbxassetid://132512888685903",
        GhostLocked   = "rbxassetid://128344634676430",
    }

    Replace the rbxassetid://... value for any icon you want to update. Upload the new image in Studio's Asset Manager first to get a valid asset ID. The key names (GridOn, GridOff, GhostUnlocked, GhostLocked) must remain unchanged — BuildModeGuiController looks them up by key.

  3. Adjust ghost appearance.

    FieldDefaultEffect
    VisualGhostTransparency0.45Opacity of main model parts during ghost preview
    CollisionBoxGhostTransparency0.65Opacity of the CollisionBox part during preview
    OtherGhostVisualTransparency0.60Opacity of other parts in other players' ghosts
    ShowCollisionBoxfalseSet true to make CollisionBox visible during preview (debug aid)
    ColorValidColor3.fromRGB(100, 210, 255)Tint when placement is valid
    ColorInvalidColor3.fromRGB(255, 80, 80)Tint when placement is blocked
    ColorTweenTime0.12 sDuration of color transition between valid/invalid states

  4. Adjust ghost movement responsiveness.

    FieldDefaultEffect
    FreeModeLerpSpeed20How quickly the ghost follows the cursor in free mode
    RotationLerpSpeed15How quickly the ghost rotates when the player rotates the item
    GhostUpdateHz20Raycast update rate (Hz) — lower values reduce CPU cost but feel less smooth

  5. Adjust the grid overlay.

    FieldDefaultEffect
    GridTextureId"rbxassetid://6372755229"Decal texture applied to build area surfaces during grid mode
    GridTransparency0.35Opacity of the grid overlay (0 = opaque, 1 = invisible)

  6. Keep the button-to-signal mapping consistent. src/StarterPlayer/StarterPlayerScripts/BuildModeGuiController.client.luau wires each toolbar button to a Signals event. If you add a new button (e.g. a new toggle), you must:

    • Add the new icon key to PlacementConfig.Icons.
    • Create a corresponding Signals entry in src/ReplicatedStorage/SharedModules/Signals/init.luau if the button drives new behavior.
    • Wire the button in BuildModeGuiController to fire/subscribe to that signal.
    • Update the signals map (and the networking map if the signal crosses the client/server boundary).

    Do not add raw RemoteEvent calls from BuildModeGuiController — all cross-boundary communication must go through Packets.

  7. Test mobile input parity. Build mode must be fully operable without a keyboard. In a Studio mobile emulation session (or on device):

    • Confirm all toolbar buttons are reachable and tap targets are large enough.
    • Confirm grid/free toggle and rotation controls work via touch.
    • Confirm the ghost follows touch drag correctly.

  8. Test desktop input parity. In a standard Studio session:

    • Confirm keyboard shortcuts for grid toggle and rotation still fire correctly after any icon or signal changes.
    • Confirm the cursor-following ghost is smooth at the configured GhostUpdateHz.

Verify​

Open build mode on both a desktop and a mobile-emulated client. Toggle grid on/off and confirm the correct GridOn/GridOff icon appears. Hover over a valid and an invalid surface and confirm the ghost color transitions. Check the Output window for any missing-asset warnings from BuildModeGuiController.
