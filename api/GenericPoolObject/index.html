GenericPoolObject

A reusable object pool for arbitrary Luau objects (not limited to Roblox Instances). Any class that exposes a new(...) constructor can be pooled — including plain Luau tables, custom OOP classes, or Roblox Instances created via Instance.new.

Unlike GenericPoolInstance, this variant does not manage CFrame teleporting or Folder parents. Recycled objects are simply held in an internal array and handed back on the next retrieval. 

local GenericPoolObject = require(path.to.GenericPoolObject)

local pool = GenericPoolObject.new(MyClass, {"arg1", "arg2"}, 10)
local obj  = pool:RetrieveObject()
-- ... use obj ...
pool:InsertObject(obj)

Clear​

</>
GenericPoolObject:Clear() → GenericPoolObject--

Returns self for chaining.

Destroys all objects currently held in the pool (when destroyable) and empties the pool array. The pool itself remains usable.

Destroy​

</>
GenericPoolObject:Destroy() → ()

Destroys all pooled objects, de-registers the pool from the global registry, wipes the pool table, and clears the metatable. The reference should be discarded afterwards.
