MotionMaster Cheatsheet

MotionMaster is the project's animation library, vendored at src/ReplicatedStorage/SharedModules/MotionMaster.luau.

Client animations must use MotionMaster — NOT TweenService

All client-side animations go through MotionMaster. Do not instantiate TweenService:Create(...) or bare TweenInfo objects anywhere in client code.

See Architecture Backbone for where MotionMaster sits in the module hierarchy.

Quick TweenService equivalence​

-- TweenService (do NOT use this in client code)
TweenService:Create(target, TweenInfo.new(0.5, Enum.EasingStyle.Quad, Enum.EasingDirection.Out), goals):Play()

-- MotionMaster equivalent
MotionMaster.Play(target, goals, { Duration = 0.5, Model = "EaseOutQuad" })

Public API​

MotionMaster.Play(target, goals, config)​

Fire-and-forget shorthand. Creates a TweenObject, calls :Play(), and returns it.

MotionMaster.Play(frame, { BackgroundTransparency = 0 }, { Duration = 0.3, Model = "EaseOutQuad" })

MotionMaster.Create(target, goals, config)​

Returns a TweenObject for manual lifecycle control. Does not start playback.

local tween = MotionMaster.Create(label, { TextTransparency = 1 }, { Duration = 0.5 })
tween:Play()

TweenObject methods​

MethodDescription
:Play()Start or restart from current elapsed position.
:Pause()Pause; preserves elapsed time.
:Resume()Resume a paused tween.
:Cancel()Pause and reset to the start value.
:Reverse()Flip direction mid-playback; elapsed time mirrors continuously.
:Scrub(alpha)Jump to a normalized position [0, 1] without playback.
:Destroy()Disconnect all connections and release memory.
:OnStep(cb)Register cb(alpha, dt) — fires every frame. Chainable.
:OnComplete(cb)Register cb() — fires when the tween finishes. Chainable.
:OnDestroy(cb)Register cb() — fires on :Destroy(). Chainable.

MotionMaster.Spring(target, prop, config)​

Creates and starts a SpringDriver that follows a dynamically updated endpoint. Supports number and Vector3 properties only.

local driver = MotionMaster.Spring(frame, "Position", { Omega = 18, Zeta = 1.0 })
driver:SetTarget(newPosition)   -- update the goal at any time

SpringDriver config fields: Omega (natural frequency), Zeta (damping ratio), MaxSubsteps, FixedDt.

SpringDriver methods: :SetTarget(v), :OnStep(cb), :IsSettled(eps?), :Stop(), :Destroy().

MotionMaster.fromPreset(presetName, target, prop)​

Instantiate a SpringDriver from one of the 16 named presets.

local driver = MotionMaster.fromPreset("UIPanel", frame, "Position")

Named spring presets​

CategoryPresets
UI / InterfaceUIPanel, UIFade, UIBounce, UISnap
CameraCameraFollow, CameraLag, CameraShake
Gameplay objectsRecoilCritical, RecoilSnappy, DoorBouncy, DoorStiff, WeaponSway, JiggleBone
EnvironmentHoverStabilizer, SpringPlatform, HeavyGate

MotionMaster.Sequence(config)​

Chain or parallelize TweenObjects. Returns a Sequence.

local seq = MotionMaster.Sequence()          -- serial (default)
seq:Add(tweenA)
seq:Add(tweenB, 0.1)   -- 0.1 s gap before tweenB
seq:Play()

local par = MotionMaster.Sequence({ Parallel = true })  -- all at once
par:Add(tweenC)
par:Add(tweenD)
par:OnComplete(function() print("all done") end)
par:Play()

Sequence methods: :Add(tweenObj, delay?), :Play(), :OnComplete(cb), :Destroy().

MotionMaster.SplineMove(target, controlPoints, config)​

Moves target (a BasePart) along an arc-length-reparameterized Catmull-Rom spline. controlPoints is an array of BasePart instances or Vector3 values (minimum 2).

local tween = MotionMaster.SplineMove(cart, { p0, p1, p2, p3 }, {
    Duration = 4,
    Model = "EaseInOutCubic",
    ConstantSpeed = true,   -- default true for SplineMove
})
tween:Play()

Returns a TweenObject (same lifecycle methods as above).

MotionMaster.PivotMove(model, targetCFrame, config)​

Animates a Model via :PivotTo(), preserving relative part offsets. Accepts a CFrame as the goal.

local tween = MotionMaster.PivotMove(door, openCFrame, {
    Duration = 0.8,
    Model = "DoorBouncy",   -- preset name accepted for Model field
})
tween:Play()

Config field reference​

FieldTypeDefaultDescription
Durationnumber1Animation length in seconds.
Modelstring or function"Smoothstep"Easing model name or custom f(t) -> alpha function.
TimeWarpstring or functionnilNonlinear time remapping applied before the alpha model.
Delaynumber0Seconds to wait before the tween starts.
Repeatnumber0Number of times to repeat after the first play.
RepeatDelaynumber0Seconds between repetitions.
Fromtablecurrent property{ propName = startValue } overrides for start values.
ConstantSpeedboolfalseArc-length reparameterization for curve-based goals.
UseSlerpbooltrueQuaternion SLERP for CFrame properties.
UsePhysicsboolfalseUse PostSimulation instead of PreRender.

Named easing models (Model field)​

"Linear", "Smoothstep", "Smootherstep", "EaseInQuad", "EaseOutQuad", "EaseInOutCubic", "EaseInCubic", "EaseOutCubic", "EaseInQuart", "EaseOutQuart", "EaseInOutQuart", "EaseInExpo", "EaseOutExpo", "EaseInOutExpo", "Spring", "Bounce".

Custom functions are also accepted: Model = function(t) return t * t end.
