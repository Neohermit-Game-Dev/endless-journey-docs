SoundManager

This item only works when running on the client. Client

Single entry point for all client audio (SFX, BGM, ambience). Call Init once from SoundController.client.luau; all other client scripts and tools call the Play*, Music, Ambience, and volume methods. Never create ad-hoc Sound instances — let SoundManager manage pooling, grouping, and replication. Asset ids, volumes, pitch ranges, and playlist definitions live in Configs/SoundConfig.

Functions​

Init​

</>
SoundManager.Init() → ()

Initialises all audio subsystems and must be called exactly once, from the client bootstrap (SoundController.client.luau).

Calling Init more than once is a no-op. On first call it:

  • Ensures SoundGroups and the positional SFX pool exist in the DataModel.
  • Connects the server-replication listener for positional sounds.
  • Pre-loads every configured asset id via ContentProvider:PreloadAsync.
  • Warms per-asset positional pools so the first PlaySFXAt is instant.
  • Auto-starts any ambience beds listed in SoundConfig.Ambience.Autostart.

PlaySFX​

) → ()

Plays a non-positional (2D) one-shot sound effect by its config name.

The sound is looked up in SoundConfig.Sfx, played through the appropriate SoundGroup, then destroyed automatically when it ends. Subject to per-asset debounce if configured.

Plays a positional (3D) one-shot sound effect anchored at position.

Uses the pooled Sound / Part system for instant playback. If opts.Replicate (or the config Replicate flag) is true, a packet is fired to replicate the sound on all other clients.

PlayLooped​

</>
SoundManager.PlayLooped(
name: string,--

Key in SoundConfig.Sfx.

opts: PlayOptions?--

Optional overrides; FadeIn fades from 0 to target volume.

) → LoopHandle?--

Control handle, or nil if the asset is not configured.

Starts a looping sound and returns a LoopHandle for runtime control.

The handle exposes :FadeTo(volume, duration?), :Stop(fadeDuration?), and :Destroy(). Returns nil if the name is unknown or has no asset id. Pass opts.FadeIn to ramp the volume up from zero on start.

PlayMusic​

</>
SoundManager.PlayMusic(
playlistName: string?--

Name of a playlist in SoundConfig; omit for the default.

) → ()

Starts the music system, optionally targeting a named playlist.

If playlistName is omitted the default playlist defined in SoundConfig is used. Calling while music is already playing performs a crossfade into the new playlist.

Beds currently playing that are absent from names are faded out; beds in names that are not yet playing are faded in.
