ActivePerksGuiController

This item only works when running on the client. Client

Binds the Studio-authored StarterGui.ActivePerksGui (Ocean Sunset gem frames, see roblox-gui-prototypes/2026-11-06-active-perks-gui-prototype.html): a read-only view of the perks buffing the player right now. Each tab lists the active permanent perks first (PerkClient), then the run's shop perks: Personal = your ActiveRun.Personal minus ended clocks; Party = every party shop perk live in the run (PartyPerkBuffs.<Id>HolderId ~= 0). A Personal perk is active at the player's own level > 0; a Party perk at the server-wide max, and OwnerBox names the player holding it (Party tab only).

Each row is styled by its type (no rarity config): PERMANENT, ONE TRIP (Consumable), TIMED (Expiring) or SUPER RARE (BoxOnly, wins over Kind). The type sets the frame colors and the gem Emblem on the top edge; the detail panel takes the selected perk's frame. Opens from a TopbarPlus icon (toggle key O). It is the Game Instance's only perk GUI: perk changes are Lobby-only (PerkMenuGuiController). Size follows the screen through MainContainer.UIScale: wide = min(W/1920, H/1022); below 0.68 the compact layout (authored at 844x332, scale clamped to [0.75, 1.5]) applies.
