Networking Map

Update this table in the same commit when you add a packet — see also the Add a Packet playbook.

All client↔server traffic goes through Packets (ReplicatedStorage/SharedModules/Packets/init.luau). Never create raw RemoteEvent or RemoteFunction instances outside that module. Reliable packets wrap a typed Packet; high-frequency positional packets use UnreliableRemoteEvent via the makeUnreliable helper.

PacketDirectionTypePurpose
ClientReadyC->SRemoteEventZero-payload announcement that the client's packet consumers are connected and it is ready to receive join-time snapshots. Fired exactly once per client, from ClientReadyController, after game.Loaded. Handled by JoinSync, which runs every registered system's sender for that player.
ReqDevHurtSelfC->SRemoteEventZero-payload dev request to damage the caller for 10% of their own max health, fired by the /hurt chat command to exercise the health HUD and damage pipeline. Handled by DevCommandsService, which gates it on place owner / group rank 250+ (the same check NovaChat's ChatHandler uses) and silently ignores unauthorised callers. Self-only by design: there is no target parameter, so a missed gate costs nothing but the caller's own health. Routed through HealthManager.ApplyDamage so armour, regen delay and death all apply.
ClientToggleGhostC->SRemoteEventNotify server that the local player entered or exited build mode (isActive, itemName). Server relays via ServerToggleGhost.
ServerToggleGhostS->AllRemoteEventBroadcast another player's build-mode state change (player, isActive, itemName).
ClientUpdateGhostC->SUnreliableRemoteEventHigh-frequency (~20 Hz) ghost CFrame stream from the local player to the server.
ServerUpdateGhostS->OthersUnreliableRemoteEventRelay of another player's ghost CFrame to all other clients.
PlaceItemC->SRemoteEventPlacement request: ray origin, ray direction, rotation degrees, isGridMode flag.
SpawnJunkS->CRemoteEventTell a client's JunkController to spawn a junk visual: (id: U16, modelName: String, startPos: Vector3F32).
SetJunkSpeedS->AllRemoteEventBroadcast new target junk movement speed (targetSpeed: NumberF32, studs/sec). First receipt snaps currentSpeed; subsequent receipts smoothstep-ramp over JunkConfig.SPEED_RAMP_DURATION. Fired on train-state changes and, per joining player, via JoinSync on ClientReady.
JunkCollectedS->AllRemoteEventNotify all clients that junk was collected (id, collector) — triggers pool cleanup.
ReqJunkClaimC->S (response)RemoteFunctionReserve junk for the requesting player (id, hitPos). Server validates cooldown and broadcasts BeginJunkRetract. Returns Boolean8 success.
ReqJunkClaimBatchC->S (response)RemoteFunctionReserve several junk in one GrabHook fire (Net Cast perk) (ids: {number}). Server clamps the count to the player's published NetCapacityBonus capacity (hard-capped at GrabHookConfig.Physics.NetMaxTargets), reconstructs each junk's position from the odometer (never trusts client positions), and broadcasts BeginJunkRetract per accepted id. Returns acceptedIds: {number} — advisory only; the client stays optimistic and ignores it. Sent by JunkController; handled by JunkService.ClaimJunkBatchForPlayer.
ReqJunkFinalizeC->S (response)RemoteFunctionAward junk after retraction completes (id). Server validates reservation then fires JunkCollected. Returns Boolean8 success.
BeginJunkRetractS->AllRemoteEventBroadcast retraction start (id, fromPos, duration, player) so every client animates its local junk visual toward the collector.
StaminaSprintIntentC->SRemoteEventSprint intent signal from client to server (isSprinting: Boolean8).
StaminaStateSyncS->CRemoteEventAuthoritative stamina sync (currentStamina: F32, isSprinting: Boolean8). Sent on every stamina/sprint change and, for the joining player's current value, via JoinSync on ClientReady.
StaminaBuffSyncS->CRemoteEventBuff state sync (isInfinite: Boolean8, regenMultiplier: F32, usageMultiplier: F32). Sent on every buff change and, to replay a joining player's current buffs, via JoinSync on ClientReady.
HealthStateSyncS->CRemoteEventAuthoritative health sync (currentHealth: F32). Sent on every health change and, for the joining player's current value, via JoinSync on ClientReady.
ReplicateSoundAtLocationC->S then S->OthersRemoteEventPositional sound replication. SoundManager sends; ReplicatedSoundService relays to other clients with rate-limit + allowlist from SoundConfig.GetReplicatedIds() (SFX defs with Replicate=true). Payload: (Location: Vector3F32, SoundConfig: {Id, Volume, Pitch}).
CreateTweenS->CRemoteEventTweenPlus: create a tween instance (id: U8, target: Instance, tweenInfo, goals).
StartTweenS->CRemoteEventTweenPlus: start a tween (id: U8, ...).
StopTweenS->CRemoteEventTweenPlus: stop a tween (id: U8).
ResetTweenS->CRemoteEventTweenPlus: reset a tween (id: U8).
DestroyTweenS->CRemoteEventTweenPlus: destroy a tween (id: U8).
ReqShredderStartC->S (response)RemoteFunctionShredder handshake step 1: validate proximity + junk count; record session start. Returns (isValid: Boolean8, holdDuration: F32, reasonCode: U8).
ReqShredderCompleteC->S (response)RemoteFunctionShredder handshake step 2: validate timing, proximity, junk count; consume junk. Returns (success: Boolean8, woodCount: U16, metalCount: U16, reasonCode: U8).
PickupItemClaimedS->AllRemoteEventProximity pickup: item claimed by a player (itemId: String, claimer: Player).
PickupItemReadyS->CRemoteEventProximity pickup: item registered and ready to hover (handle: BasePart, itemId: String). Triggers HoverEffect on client. Every still-Unclaimed item is replayed to a joining player via JoinSync on ClientReady.
RequestDropC->SRemoteEventDrop the active craft-material Tool. No payload — server infers item from character:FindFirstChildWhichIsA("Tool") and spawns a world handle with an impulse.
ReqStashPlaceableC->S (response)RemoteFunctionValidate + destroy placed model + grant Tool to Backpack (targetModel: Instance). Returns (success: Boolean8).
ReqMovePlaceableC->S (response)RemoteFunctionSame as Stash but also auto-equips the Tool when a Humanoid exists (targetModel: Instance). Returns (success: Boolean8).
BroadcastPlaceablePoofS->AllRemoteEventVisual + sound poof cue at destroyed model location (pivot: CFrameF32U16, placeableName: String, isMove: Boolean8). Played by every client.
RequestPlacementRevertC->S (response)RemoteFunctionCancel a Move session and revert the item to its stored original spot if free. No payload. Returns Boolean8 reverted. Sent by PlacementClient (cancelPlacement); handled by PlacementServer (OnServerInvoke). Reads PlaceableRevertStore; returns true if the item was re-placed, false if the spot was occupied or no entry existed (client then unequips the tool to Backpack).
TrainStateSyncS->AllRemoteEventBroadcast train fuel state (fuel: F32, rate: F32, isBraked: Boolean8, isStalled: Boolean8, serverTime: F64). Fired on events (refuel, brake toggle, stall, resume, init) and, per joining player, via JoinSync on ClientReady. Clients extrapolate locally between events.
SetMusicContextS->CRemoteEventSwitch the client's BGM context (context: String) — a playlist name in SoundConfig.Music.Playlists. Fired by MusicService.SetContext from server gameplay events (pirate attack, outpost/camp). MusicDirector consumes it; "Normal" clears combat.
ReqRefuelTrainC->S (response)RemoteFunctionFeed Energy junk into engine (smallest-first, up to cap) (engine: Instance). Returns (success: Boolean8, fuelAdded: F32, reasonCode: U8).
ReqToggleBrakeC->S (response)RemoteFunctionToggle brake lever (lever: Instance). Returns (success: Boolean8, isBraked: Boolean8, reasonCode: U8).
ReqMeleeSwingC->SRemoteEventRequest a melee swing. No payload — server infers the weapon from the equipped Tool, validates rate/combo, and applies authoritative damage via CombatService.
WeaponImpactS->AllRemoteEventBroadcast a melee/impact hit so every client renders impact FX + sound (position: Vector3F32, weaponName: String). Consumed by WeaponEffectsController.
ReqFireWeaponC->SRemoteEventFire the equipped hitscan gun (origin: Vector3F32, direction: Vector3F32). Server infers the weapon from the equipped Tool and validates rate/ammo/reload-lock/origin-distance, then casts its own authoritative range-capped ray. Non-finite origin/direction are rejected.
ReqReloadWeaponC->S (response)RemoteFunctionReload the equipped gun. No payload. Returns (accepted: Boolean8, reloadTime: NumberF32) (0 if rejected). On accept the server schedules the magazine refill and pushes WeaponMagSync + AmmoPoolSync at completion.
WeaponFiredS->AllRemoteEventBroadcast a gun shot so non-shooters render tracer/impact (shooter: Instance, weaponName: String, origin: Vector3F32, endpoint: Vector3F32, isHit: Boolean8). shooter is a Player for player guns or an enemy Model for EnemyWeapon fire. WeaponEffectsController ignores the local player (the shooter draws its own tracer in GunHandler); enemy Model shooters always render. FX sound lookup goes through WeaponFx.resolve, which checks WeaponConfig then EnemyCombatConfig.FindByWeapon.
WeaponMagSyncS->CRemoteEventAuthoritative magazine count to the owning client (weaponName: String, mag: NumberU16). Sent on equip, after each shot, and on reload completion; reconciles GunHandler's predicted magazine via AmmoApi.
AmmoPoolSyncS->CRemoteEventAuthoritative pool count to the owning client (ammoType: String, amount: NumberU16). Fired by AmmoManager on every pool mutation (shot, reload, craft); reconciles AmmoApi's cached pool.
ReqThrowProjectileC->SRemoteEventThrow the equipped throwable (grenade or C4) (origin: Vector3F32, direction: Vector3F32). Server infers the weapon from the equipped Tool, validates Throwable category/cooldown/origin-distance (NaN-safe), and spawns a server-owned, replicated physics projectile via ServerProjectile. Grenade detonates on a fuse timer; C4 (Manual) is tracked and detonated by ReqDetonate. Non-finite origin/direction are rejected.
ReqDetonateC->SRemoteEventDetonate all of the requester's active manual throwables (C4). No payload. WeaponServer.onDetonate reads each tracked instance's position and detonates via CombatService.ApplyAOE + ExplosionAt, destroying the instances.
ExplosionAtS->AllRemoteEventBroadcast an explosion so every client (including the source) renders one boom FX + sound (center: Vector3F32, radius: NumberF32, weaponName: String). Used by rocket + grenade + C4; damage is applied server-side via CombatService.ApplyAOE.
XPStateSyncS->CRemoteEventAuthoritative XP snapshot to the owning client (level: U8, xpIntoLevel: U32, xpForNextLevel: U32). Sent on profile load and every XP change, plus via JoinSync on ClientReady (covers a profile that loaded before the client was ready); bridged to Signals.OnXPChanged by XPController.
XPLevelUpS->CRemoteEventNotify the owning client they leveled up (level: U8). XPController shows a toast; reserved as the hook for future level rewards.
CoinStateSyncS->CRemoteEventAuthoritative coin balance to the owning client (balance: U32). Sent on profile load and every balance change, plus via JoinSync on ClientReady (covers a profile that loaded before the client was ready); bridged to Signals.OnCoinsChanged by CoinController.
ReqResearchSnapshotC->S (response)RemoteFunctionRequest the full Research Bench snapshot on GUI open / join. No payload. Returns (state: Any) — serialized { levels, active, queue, fuel }.
ReqResearchEnqueueC->S (response)RemoteFunctionEnqueue the next level of a node (nodeId: String). Pays the level's full material cost immediately on success (pay-on-enqueue). Returns (success: Boolean8, reason: NumberU8) (ResearchResultCodes).
ReqResearchCancelC->S (response)RemoteFunctionCancel a node's job at (nodeId: String, fromLevel: NumberU8) and every already-queued higher level of that node (cascade-cancel). Queued refunds are full; the active job (if matched) refunds at ResearchConfig.ACTIVE_REFUND_FRACTION. Returns (success: Boolean8, reason: NumberU8).
ReqResearchRefuelC->S (response)RemoteFunctionFeed a held Energy tool into the bench fuel reserve via EnergyToolHelper. No payload. Returns (success: Boolean8, reason: NumberU8).
ResearchStateUpdateS->AllRemoteEventFull state broadcast { state: {levels, active, queue, fuel}, serverTime: F64 }. Fired on every enqueue/cancel/refuel and on level completion; also a low-frequency drift-correction broadcast (every ResearchConfig.HEARTBEAT_BROADCAST_INTERVAL) while a job is active. Clients interpolate elapsed time/fuel locally between broadcasts.
ReqAllocatePerkC->S (response)RemoteFunctionSpend one point on a perk (perkId: String). Server validates via PerkState.canAllocate and mutates PerkLevels; a locked perk is rejected with PERK_LOCKED before any point math. Returns (success: Boolean8, reasonCode: NumberU8) (PerkResultCodes).
ReqUnlockPerkC->S (response)RemoteFunctionUnlock a perk (perkId: String): pays its one-time UnlockCost in coins, gated by the player's XP level (UnlockLevel). Server validates via PerkState.canUnlock (order: unknown → already unlocked → level → coins) and deducts via CoinManager.DeductCoins. Does not affect buffs — OnPerkStateChanged is not fired. Returns (success: Boolean8, reasonCode: NumberU8) (PerkResultCodes: ALREADY_UNLOCKED, LEVEL_REQUIRED, NOT_ENOUGH_COINS, etc.).
ReqRespecPerksC->S (response)RemoteFunctionRespec a pool (pool: NumberU8): 0 = both, 1 = Personal, 2 = Party. Clears matching PerkLevels and Unlocked entries (points return automatically), refunds each cleared perk's UnlockCost via CoinManager.RefundCoins (exact, un-inflated), then re-seeds free starters. Returns (success: Boolean8).
PerkStateSyncS->CRemoteEventAuthoritative perk snapshot to the owning client (perkLevels: Any, unlocked: Any, personalAvailable: NumberU8, partyAvailable: NumberU8, playerLevel: NumberU16). Sent on profile load, allocate, unlock, respec, level-up, and via JoinSync on ClientReady (covers a profile that loaded before the client was ready).
TrainShieldSyncS->AllRemoteEventBroadcast authoritative shield state (currentShield: F32, maxShield: F32). Event-driven (on damage, recharge, or buff change) and, per joining player, via JoinSync on ClientReady. No serverTime — the shield has no continuous drain, so clients need no extrapolation. Consumed by TrainShieldController → writes TrainStateCache → fires Signals.OnTrainShieldChanged (currently no subscriber; see Signals Map).
ReqRechargeShieldC->S (response)RemoteFunctionFeed the player's Energy tools into a ShieldConsole (smallest-ShieldRecharge-value-first, up to maxShield, never over-filled) (console: Instance). Returns (success: Boolean8, shieldAdded: F32, reasonCode: U8) (TrainResultCodes). Mirrors ReqRefuelTrain.
SyncSettingsS->CRemoteEventDeliver a player's full saved settings map ({ [string]: any }). Sent on profile load, plus via JoinSync on ClientReady (covers a profile that loaded before the client was ready). Fired by SettingsManager; consumed by SettingsClient, which applies (never re-saves) each valid entry.
SaveSettingC->SRemoteEventPersist one setting change (key: String, value: Any). Sent by SettingsClient (debounced); validated server-side by SettingsManager via SettingsSchema before being written to the profile.
ChatEditMessageC->SRemoteEventEdit a message's text (messageId: String, newText: StringLong).
ChatDeleteMessageC->SRemoteEventDelete a message (messageId: String).
ChatPinMessageC->SRemoteEventPin a message (pinData: Any). Not currently handled server-side (pre-existing gap, not introduced by the Packets migration).
ChatUnpinMessageC->SRemoteEventUnpin the current message. No payload. Not currently handled server-side.
ChatSetPendingReplyC->SRemoteEventAnnounce the player's reply-compose state (replyData: Any). Server relays via ChatPendingReplyUpdated.
ChatSetPendingChannelC->SRemoteEventAnnounce the player's channel selection (channelName: String). Server relays via ChatPendingChannelUpdated.
ChatSetPendingImageC->SRemoteEventAnnounce the player's pending image attachment (imageId: F64). Server relays via ChatPendingImageUpdated.
ChatSetPendingVideoC->SRemoteEventAnnounce the player's pending video attachment (videoId: F64). Server relays via ChatPendingVideoUpdated.
ChatTypingStartC->SRemoteEventThe player started typing. No payload. Server broadcasts via ChatTypingUpdate.
ChatTypingStopC->SRemoteEventThe player stopped typing. No payload. Server broadcasts via ChatTypingUpdate.
ReportSubmitC->SRemoteEventSubmit a player report (data: Any). Relayed cross-server via MessagingService; allowed admins receive it via ReportReceived.
ReportAdminActionC->SRemoteEventAdmin moderation action (ban/kick/mute/block-reports) (data: Any), sent from the in-chat admin embed.
ReactionToggleC->SRemoteEventToggle the local player's reaction on a message (messageIdentifier: String, emojiData: String). Server broadcasts the result via ReactionUpdated.
ChatTypingUpdateS->AllRemoteEventBroadcast the current set of typing players (typingPlayers: Any, { [userId]: displayName }).
ChatPendingChannelUpdatedS->AllRemoteEventRelay another player's channel selection (senderId: F64, channelName: String).
ChatPendingReplyUpdatedS->AllRemoteEventRelay another player's reply-compose state (senderId: F64, replyData: Any).
ChatPendingImageUpdatedS->AllRemoteEventRelay another player's pending image attachment (senderId: F64, imageId: F64).
ChatPendingVideoUpdatedS->AllRemoteEventRelay another player's pending video attachment (senderId: F64, videoId: F64).
ChatMessageUpdatedS->AllRemoteEventA message's text was edited (messageId: String, newText: StringLong, editorUserId: F64).
ChatMessageRemovedS->AllRemoteEventA message was deleted (messageId: String, deleterUserId: F64).
ChatPinUpdatedS->AllRemoteEventThe pinned message changed (pinData: Any). Not currently fired server-side (pre-existing gap; see ChatPinMessage).
ChatPinRemovedS->AllRemoteEventThe pinned message was cleared. No payload. Not currently fired server-side.
ChatSystemMessageS->CRemoteEventA system-style chat message to one client (text: StringLong), e.g. the report-block notice.
ReportReceivedS->CRemoteEventA player report delivered to allowed admins (data: Any), relayed cross-server via MessagingService (see ReportSubmit).
ReactionUpdatedS->AllRemoteEventBroadcast the result of a reaction toggle, including the reactor (messageIdentifier: String, emojiData: String, reactorName: String).
DisruptionBeganS->AllRemoteEventBroadcast that a shutdown/maintenance drain has begun (reason: String, seconds: U8). reason keys into DisruptionConfig.REASON_MESSAGES; seconds is the notice window before teleport. Sent by DisruptionCoordinator; received by DisruptionController.client.
ReqClaimQuestC->S (response)RemoteFunctionClaim a completed quest's reward (questId: String). Server validates (active set, progress ≥ target, not already claimed) via QuestManager.ClaimQuest. Returns (ok: Boolean8, reason: NumberU8, coins: NumberU32, exp: NumberU32) (QuestResultCodes; amounts are 0 on any failure).
QuestStateSyncS->CRemoteEventAuthoritative quest snapshot to the owning client (dailyPeriod: NumberU32, weeklyPeriod: NumberU32, dailyExpiresAt: NumberU32, weeklyExpiresAt: NumberU32, dailyProgress: Any, weeklyProgress: Any, dailyClaimed: Any, weeklyClaimed: Any, lifetime: Any, seasonPeriod: NumberU32, seasonExpiresAt: NumberU32, seasonProgress: Any, seasonClaimed: Any). Period indices + expiry timestamps let the client recompute the active set via QuestState.selectQuests and drive a countdown without extra traffic; the season* fields (added for the Battle Pass's Scope = "Season" quests) use BattlePassState.seasonIndex/seasonExpiresAt as their period. Sent on profile load, progress report, claim, rollover, and via JoinSync on ClientReady (covers a profile that loaded before the client was ready).
ReqLeaveToLobbyC->SRemoteEventDeliberate "leave to lobby" intent. No payload — marks the departure clean so SessionCoordinator clears the player's roster entry + session pointer immediately instead of holding a rejoinable grace session. Sent by SessionClient (forwarding Signals.LeaveToLobbyRequested); handled by SessionCoordinator. See Party Lock + Mid-Run Rejoin.
ReqClaimBattlePassC->S (response)RemoteFunctionBulk-claim every unlocked-but-unclaimed tier reward across both rows in one shot (no payload). Server computes everything from the player's derived level via BattlePassManager.ClaimBattlePass. Returns (ok: Boolean8, reason: NumberU8, freeCount: NumberU16, premiumCount: NumberU16, coins: NumberU32) (BattlePassResultCodes; counts/coins are 0 on any failure).
ReqPromptPremiumC->S (response)RemoteFunctionOpen the Roblox subscription purchase prompt for the premium battle pass. No payload — the prompt must originate server-side. Returns (prompted: Boolean8) (false while BattlePassConfig.SUBSCRIPTION_ID is unset).
BattlePassStateSyncS->CRemoteEventAuthoritative battle pass snapshot to the owning client (seasonIndex: NumberU32, exp: NumberU32, level: NumberU8, expIntoLevel: NumberU32, expForNextLevel: NumberU32, claimedFree: Any, claimedPremium: Any, isPremium: Boolean8, seasonExpiresAt: NumberU32). Level + progress are derived server-side via BattlePassState; claimed maps are keyed by tier level. Sent on profile load, EXP gain, claim, rollover, premium status change, and via JoinSync on ClientReady (covers a profile that loaded before the client was ready). See Battle Pass.
JumpStateSyncS->AllRemoteEventBroadcast the complete jump-drive state (phase: String, biomeId: String, phaseEndsAt: NumberF64, charge: NumberF32, ballots: Any). Phase, gauge, and ballots travel together so a client can never render a phase and a gauge from two different moments. phaseEndsAt is a workspace:GetServerTimeNow() deadline (0 = indefinite hold, e.g. InWormhole); clients extrapolate their own countdown, the same pattern TrainStateSync uses. ballots is { [userId: number]: boolean }, empty outside Voting. Fired on every state change and, per joining player, via JoinSync on ClientReady. See Jump Drive.
ReqDepositJumpChargeC->S (response)RemoteFunctionFeed all suitable Energy tools into the jump drive, smallest-tier-first, up to MAX_CHARGE (bench: Instance). Returns (success: Boolean8, chargeAdded: NumberF32, reasonCode: NumberU8) (JumpDriveResultCodes).
ReqStartJumpVoteC->S (response)RemoteFunctionOpen a party jump vote. Requires standing at the bench and phase Ready; the opener is recorded as an automatic yes (bench: Instance). Returns (success: Boolean8, reasonCode: NumberU8).
ReqCastJumpVoteC->S (response)RemoteFunctionCast or change a ballot while Voting. Deliberately has no proximity requirement — the vote banner is pushed to every player wherever they are (approve: Boolean8). Returns (success: Boolean8, reasonCode: NumberU8).
