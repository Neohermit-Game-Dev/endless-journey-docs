LeviathanBrain

The Leviathan fight as a pure state machine (no instances, no time), plus the per-visit scaling maths. LeviathanService feeds it events and plays the action it returns.

Cycle (user design): RiftIn -> Prowl -> Slam or SwarmScream (50/50, never two swarm calls in a row). Slam -> Prowl. SwarmScream -> RiftOut -> Away until the swarm is cleared -> RiftIn. After every AttacksPerLaser attacks: Prowl -> Frenzy -> Laser -> SwarmScream (not counted as an attack) -> RiftOut -> Away. 

local brain = LeviathanBrain.new(Random.new())
local action = brain:Next("Arrived") -- "RiftIn"
