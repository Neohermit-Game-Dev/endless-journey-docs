WeaponPose

Turns a player's weapon pose (WeaponPoseSchema) into the CFrames and the size of the hold. One module for the server (ToolGripService) and the client (WeaponIK), so both agree. Zero pose = today's HoldAnimConfig values, exactly. Turns use the Handle axes (X along the barrel): yaw about Y, pitch about Z, roll about X. toolGrip is the Tool's Grip (the RightGrip's C1), after Tool:ScaleTo(eff.scale). gun.x/y/z moves the weapon along its own Handle axes for every weapon (+X = toward the muzzle = forward, +Y = up, +Z = right). Two-hand: it moves the right-hand IK target. One-hand (WeaponPoseConfig.OneHand): it moves the weapon in the hand.

Right-hand IK target, in RightShoulderRigAttachment space: HoldAnimConfig.RightHand scaled by the arm reach, moved by gun.x/y/z along the Handle axes (not the shoulder's: the waist twist of the aim pose turns those away from the barrel) and turned about the grip point.

gripFor​

</>
WeaponPose.gripFor(
toolName: string,
handSize: Vector3?,
eff: Effective,
toolGrip: CFrame
) → CFrame

RightGrip C0 and right-hand IK end effector (RightHand space): HoldAnimConfig.gripFor, then

  • two-hand: the hand moved by right.x/y/z and turned by right.yaw/pitch/roll in Handle space about the grip point (the gun stays; the hand moves);
  • one-hand: the weapon moved by gun.x/y/z in Handle space (the hand stays).
