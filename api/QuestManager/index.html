QuestManager

This item only works when running on the server. Server

Place-agnostic authority for daily/weekly quests. Owns the PlayerQuests ProfileStore profile (one session per player, key = UserId), rotation/rollover, progress, claim, lifetime stats, and per-player replication via QuestStateSync.

Runs in BOTH the lobby and gameplay places (lobby needs display + claim). The progress SOURCES (kills, distance, junk) live in the gameplay-only QuestSourcesLoader, not here — mirroring XPManager / XPSystemLoader.

Cross-place: STORE_NAME + tostring(UserId) key are identical in every place, so the same DataStore record is shared; ProfileStore session-locking serialises the lobby↔gameplay handoff. The active quest SET is never stored — QuestState recomputes it deterministically from the period index.

Report an ownerless world metric (e.g. an enemy died, train distance ticked). Advances every player's Party quests and credits each their lifetime metric total. Personal quests are untouched (no single actor).

Claim a completed quest's reward. Idempotent: the claimed flag is set BEFORE the grant, so a re-entrant call cannot double-pay. Returns (ok, reasonCode, coinsGranted, expGranted); amounts are 0 on any failure.
