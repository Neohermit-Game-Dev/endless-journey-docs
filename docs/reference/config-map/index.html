Config Map

Update this table in the same commit when you add a config module — see also the relevant system playbook linked in each row.

All tuning lives in config modules under src/ReplicatedStorage/SharedModules/Configs/. Prefer config changes over code changes when adjusting gameplay feel. The modules are accessible from both client and server.

ConfigPrimary Controls
PlacementConfigGhost update frequency, ghost visuals, grid texture, icon assets, top-down build camera (pan/zoom/edge scroll, entry move, checkerboard exit), MaxPlacedPerItem, PlaceableActions (cooldown, poof, MaxActionDistance, turret hold prompts PromptHoldDuration (0.6 s), StashPromptText / MovePromptText, StashKey (F) / MoveKey (G), StashGamepadKey / MoveGamepadKey). See Placement.
PlatformConfigTrain platform extension: STARTING_PLATFORMS (platforms built at server start; minimum 2 is enforced), per-platform Wood/Metal Costs, deposit prompt (key F, hold time, distance, server tolerance, cooldown), ghost look, scan-sweep reveal timing, Attr names (incl. RearX, the built train's rear end that sets the shield length). See Train Platforms.
JunkConfigSpawn rate, server/client caps, tier/type weights, speed/direction, pity threshold, speed-ramp duration. Energy Yield is the Energy junk's material pool point value (T1–T5: 10/20/40/60/100), credited on grab. Special (perk-only junk, e.g. Cache with a Yield table; models from JunkAssets.Special.<name>). See Junk Flow playbook.
DebrisConfigDecorative floating debris (client-only): DEFAULT_SPAWN_CHANCE per junk spawn (0.25) and per-biome SpawnChance (Void 0.6), MAX_CLIENT_DEBRIS cap, spawn offsets from the junk start (SPAWN_OFFSET_X/_YZ, JUNK_GAP, SPAWN_RETRIES), train corridor CLEARANCE_SIDE/_ABOVE/_BELOW, ROT_SPEED, ASSET_WAIT_SECONDS (debris turns off if ReplicatedStorage.DebrisAssets is missing). Models from ReplicatedStorage.DebrisAssets. See Junk — Decorative debris.
StaminaConfigMax stamina, drain/regen rates, regen delay, sprint speed multiplier, FOV delta, buff defaults, SprintIcons (mobile sprint toggle Walk/Sprinting images). See Tune Stamina playbook.
HealthConfigHPMultiplier (scales max HP, damage taken, regen and heals; every other HP number in configs is at 100-HP scale), max health, regen rate, regen delay.
GrabHookConfigBeam appearance, projectile behavior, max distance, grapple-loop fade timings. (Sound assets live in SoundConfig.)
CameraConfigThird-person + aim offsets, offset-spring tuning (Omega/Zeta), per-mode look angle (ShootingLookAngle/ThirdPersonLookAngle), reticle config, CameraBoom zoom range, raycast buffer, smoothing.
NotificationConfigToast types/colors/imageIds, per-type SFX names, device sizing, animation timing, MaxConcurrent cap, ExecutedFunctionTimeout.
ShredderConfigInteract distance, hold duration range, anti-exploit tolerances, client arc params (ARC_*, LANDING_SCATTER_RADIUS), CollectionService tag, trajectory/material folder names, PROCESS_ANIMATION_ID (workbench processing animation).
MaterialHudConfigMaterials HUD toggle key (LeftControl), show/hide timing, panel sizing, mockup colors, and fly-to-HUD effect tuning. See Material Pool.
JunkToolConfigTool textures keyed by junk name.
ProximityPickupConfigDetection radius, float animation duration, hover/spin params, drop-landing: SETTLED_VELOCITY_THRESHOLD, DROP_POLL_INTERVAL, DROP_LANDING_TIMEOUT. DroppableSurface CollectionService tag controls which surfaces dropped items land on.
TrainConfigMax fuel, running/stopped drain rates (stopped = 0: braked burns no fuel), proximity tolerance, engine/lever CollectionService tags + prompt part names, brake action text, FUEL_PER_POINT (fuel per pool Energy point). Refuel animation (client-cosmetic): REFUEL_ATTR (engine attribute, holder UserId), REFUEL_HOLD_GRACE, CHUTE_ATTACHMENT_NAME, REFUEL_FX (cell path/interval/flight/arc/scale, bounce period/stretch/lean/axis/ramps). Brake lever animation (client-cosmetic): BRAKE_LEVER_ANIM_ID, BRAKE_LEVER_REST_IS_BRAKED, BRAKE_LEVER_SWING_DEG, BRAKE_LEVER_SWING_TIME, BRAKE_LEVER_SWING_MODEL. Shield: BASE_SHIELD, SHIELD_AUTOREGEN_PCT/SHIELD_AUTOREGEN_INTERVAL (Shield δ regen, 0.5% per 10 s; Shield Capacitor doubles it), SHIELD_NOVA_RADIUS/SHIELD_NOVA_COOLDOWN/SHIELD_NOVA_KNOCKBACK (Shield Nova perk), SHIELD_CONSOLE_TAG, SHIELD_PROMPT_PART_NAME/SHIELD_ZOOM_PROMPT_PART_NAME (the console's two prompts), SHIELD_MONITOR_TAG, CORE_TAG (Shield Nova center; falls back to the engine), SHIELD_PER_POINT (shield per pool Energy point), FUEL_DAMAGE_FACTOR (0.05 — shield-down bleed-through: fuel lost = attackDamage * FUEL_DAMAGE_FACTOR, routed TrainShieldManager.ApplyDamage → TrainFuelManager.ApplyFuelDamage). Both client and server resolve prompt parts recursively via PromptResolver. Shield monitor display: ShieldBands + SHIELD_BAND_HYSTERESIS (health band text + Color/Readout/Tint/Gloss colours), ShieldImages (Normal/Critical icon), ShieldStrengthRatings, and the three SHIELD_*_BUFF_KEY names the readout looks up on ResearchBuffs (the Tech Tree writes them; only ShieldAutoRegen changes server behavior). See Train Fuel and Train Shield. Shield dome (see Train Shield — Dome): DOME_NAME ("ShieldDome"), DOME_RADIUS_ATTRIBUTE ("Radius"), SHIELD_HIT_VFX ("ShieldHitVFX"), severity ranges SHIELD_HIT_SIZE_SCALE (1.8), SHIELD_HIT_COUNT_SCALE (2), SHIELD_HIT_VOLUME_SCALE (1), SHIELD_FLASH_LEVEL (1), SHIELD_HIT_HOLD (1.25), SHIELD_HIT_FADE (0.25), reveal SHIELD_REVEAL_INTERVAL (120), SHIELD_REVEAL_LEVEL (0.9), SHIELD_REVEAL_HOLD (10), SHIELD_REVEAL_FADE (1), flicker keys SHIELD_BREAK_KEYS, SHIELD_REBOOT_KEYS; shield tube SHIELD_TUBE_TEMPLATE ("ShieldTubeSegment"), SHIELD_TUBE_SEGMENT (36), SHIELD_REAR_INSET (3.8), SHIELD_VISUALS_FOLDER ("ShieldVisuals").
TrainGameOverReason (enum module, not a tuning config)Frozen numeric enum identifying how a round ended: NONE = 0, HULL_BREACHED = 3 (shield 0 + fuel 0, then ThreatConfig.HULL_HITS regular hits), LEVIATHAN_STRIKE = 4 (shield 0 + fuel 0, then one ThreatConfig.BOSS_DAMAGE_SOURCE hit), ALL_DOWN = 5 (every player down and the ReviveConfig.ALL_DOWN_SECONDS countdown ended; triggered by ReviveService, see Paid Revive). Codes 1 and 2 (the old fuel-out reasons) are retired and never reused. Lives in ReplicatedStorage/SharedModules/TrainGameOverReason.luau. Stored by TrainGameOver.Trigger/GetReason and broadcast via Signals.OnTrainGameOver. See Train Shield — Hull.
SoundConfigAll game audio: per-name SFX defs (id/volume/pitch/group/replicate/debounce), BGM playlist defs (timing, Role, PerBiome, fallback Tracks; track ids come from ReplicatedStorage.BGMs via BgmFolder "BGMs", SharedFolder "Shared", BiomeFolders biome id → subfolder), ambience bed defs (Ambience.Beds; Ambience.PerBiome biome id → bed names: Volcano lava beds, Ice ColdWind + Snowstorm, Storm StormPassing + RainOnWater, Void SpacePresence1 + SpacePresence2; and Ambience.BiomeFade (3 s), used by BiomeController — see Biomes), per-bus group volumes. Normalize (loudness normalizer: Enabled, TargetDb −18, MinGain 0.25, MaxGain 4, Samples 4000, GateDb −60) and InteractionGroup ("SoundManager", shared by SoundManager's emitters and listener). Helper: GetReplicatedIds() (server relay allowlist). Consumed by SoundManager.
SettingsConfigUser-preferences definitions registry (pure data) — single source of truth for the settings system. Definitions table keyed by setting name: per-key type/default/min/max/step/options, plus category/label/order for GUI grouping/display. VolumeBusByKey maps volume setting keys to their SoundConfig bus. STORE_NAME ("PlayerSettings") for ProfileStore. AUDIO_DEFAULTS_VERSION (bump after a SoundConfig.GroupVolumes default change; saved profiles below it get the current volume defaults once). GetDefaults() returns a fresh key→default map. See Settings (User Preferences).
WeaponConfigPer-weapon registry keyed by Tool name: category (Gun/Throwable), damage + DamageType (Bullet/AOE), gun fire-rate (RPM/Automatic)/ammo (MagazineSize/AmmoType/ReloadTime)/Spread/MaxDistance/HeadshotMultiplier, projectile + throwable AOE (AOERadius/AOEDamage), FuseTime/Detonation/MaxActive, and per-weapon SoundConfig keys. ReserveMax and CarryCount have been removed — guns use AmmoType to reference a pool in AmmoConfig; throwable count is inferred from Backpack Tool instances. See Weapons system.
AmmoConfigAmmo type definitions and gun→type mapping. AmmoTypes table: { Light = {DisplayName, Capacity=300, Starting=0}, Heavy = {DisplayName, Capacity=60, Starting=0}, Rocket = {DisplayName, Capacity=12, Starting=0} }. All Starting values are 0 — players get no free reserve ammo; reserve is crafted (a freshly crafted weapon still spawns with one full magazine). WeaponAmmo map: Pistol/SMG/AR → Light, SR → Heavy, RocketLauncher → Rocket. Pool is session-only (no DataStore); cleared on leave. AmmoManager.EnsureStarting seeds each type to its Starting amount on the player's first spawn only; the pool then persists across death for the rest of the session (dying never refills reserve ammo). See Weapons system.
ResearchConfigBench tag ("ResearchBench" — carried by the PlaceableItems template and inherited by placed clones, so lookups must filter to workspace descendants) + prompt part name ("TechPromptPart"), interaction distances, queue/fuel constants (QUEUE_MAX = 3, FUEL_BURN_RATE, ACTIVE_REFUND_FRACTION, FUEL_PER_POINT, TICK_INTERVAL, HEARTBEAT_BROADCAST_INTERVAL), hold-to-refuel pacing (HOLD_TICK = 0.1, REFUEL_POINTS_PER_TICK = 1, MAX_HOLD_POINTS = 255 (one hold pays at most this much Energy, the ReqResearchRefuel U8 limit), HOLD_TIMEOUT = 30 s (how long one held REFUEL may freeze the bench without a release)); bench fuel has no cap, BIOME_SELECTOR_GAMEPASS_ID (1982397425, the gamepass gate on Special_BiomeSelector; 0 would mean unset and lock the node, not free it), NodeStateColors (per-state Background/Stroke/NameText/StatusText/StatusIcon/Line palette for the five card states) and IN_PROGRESS_PULSE, Icons (23 image ids for the tech tree GUI, all uploaded), Branches (tab order: Id, DisplayName, Icon), MAX_TIER (5, the rows the tree canvas fits), EffectLabels (how each StatBuff key reads in the detail panel), and the 31-node Nodes table (Branch + Tier + Column place the card, Prereqs list with AND semantics draws the lines, MaxLevel (always 1 today), Unlocks or Effects fill the detail panel, Gamepass, per-level Cost/Duration). There is no Category field. See Research Bench system and Tune Research Bench playbook.
ChronoConfigChrono library setup: CHECK_NEW_VERSION = false; ENEMY entity type (TICK_RATE 1/30, dynamic BUFFER, NATIVE mode, NORMAL_TICK_DISTANCE 150, HALF_TICK_DISTANCE ∞, STORE_SNAPSHOTS = true — required for lag-compensation rewind).
