NpcHealth

One way to read, damage and watch NPC health, for both kinds of body: Humanoid NPCs (void enemies, pirate ship, Leviathan) and attribute NPCs (number attributes Health + MaxHealth on the Model, e.g. pirate boarders, which have no Humanoid). damage and setMax are server-only; clients read the replicated values.
