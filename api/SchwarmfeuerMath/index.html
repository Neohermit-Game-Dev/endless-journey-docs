SchwarmfeuerMath

Pure salvo and missile math shared by the server (SchwarmfeuerServer: authority) and the client (SchwarmfeuerController: missile visuals), so both sides split a salvo and steer a missile the same way. Directions are unit vectors; the config is passed in so this module stays pure.

Functions​

salvoTargets​

</>
SchwarmfeuerMath.salvoTargets(
locks: {T},
total: number
) → {T}

Smart divide: the target of each of the total missiles in launch order, round-robin over locks (1 lock gets all; 5 locks of 12 get 3, 3, 2, 2, 2). Empty when there are no locks (the salvo flies unguided).

stepMissile​

</>
SchwarmfeuerMath.stepMissile(
pos: Vector3,
dir: Vector3,
age: number,
target: Vector3?,
dt: number,
cfg: any
) → (
Vector3,
Vector3
)

One flight step. Straight while age < BoostTime or without a target; else dir turns toward the target by at most TurnRateDeg deg/s, raised near the target so the turn radius never exceeds half the distance to it (a missile could otherwise orbit a close or off-axis target). Returns the new position (dir * MissileSpeed * dt on) and the new unit direction.

retarget​

</>
SchwarmfeuerMath.retarget(
salvo: {T},
isAlive: (T) → boolean,
pointOf: (T) → Vector3,
from: Vector3
) → T?

The live entry of salvo nearest to from (a missile whose target died picks another lock of its salvo), or nil when none is alive.

bestPlayDPS​

</>
SchwarmfeuerMath.bestPlayDPS(cfg: any) → number

Best-play single-target DPS (splash ignored): one full salvo per cycle.

autoCycleDelay​

</>
SchwarmfeuerMath.autoCycleDelay(
cfg: any,
autoRate: number
) → number

Extra wait after an unmanned salvo so unmanned fire runs at autoRate x the manned cycle (Smart Cannon / Orbital Sentinel). math.huge when off.

validLocks​

</>
SchwarmfeuerMath.validLocks(
list: {any},
isEnemy: (any) → boolean,
pointOf: (any) → Vector3,
pivot: Vector3,
barrelDir: Vector3,
cfg: any
) → {any}

The server's view of a gunner's lock list: keeps entries isEnemy accepts, once each, within MaxRange of pivot and within ServerLockConeDeg of barrelDir, in their order, at most MagazineSize of them.

canFire​

</>
SchwarmfeuerMath.canFire(
seated: boolean,
reloading: boolean,
ammo: number,
cfg: any
) → boolean

A salvo may start only from a seated gunner with loaded pods. A short train ammo pool can leave a partial magazine, which fires a partial salvo; a salvo still launching is blocked by the caller's queue check.

podsIdle​

</>
SchwarmfeuerMath.podsIdle(
trigger: boolean,
queued: number,
reloading: boolean,
sinceRelease: number,
cfg: any
) → boolean

True when open pods with nothing to fire should close: trigger up for at least PodCloseGrace (the release's Fire packet comes a frame later), no salvo queued, not reloading (the reload closes them itself).

firstLaunchAt​

</>
SchwarmfeuerMath.firstLaunchAt(
now: number,
openedAt: number,
cfg: any
) → number

Earliest launch time of a salvo's first missile: once the doors, opened at openedAt, have finished their DoorOpenTime swing.

selfCheck​

</>
SchwarmfeuerMath.selfCheck() → ()

Asserts the salvo split, the homing step, retargeting and the balance target. Run in Studio (edit mode) through a fresh-require shim.
