BattlePassManager

This item only works when running on the server. Server

Authority for the monthly battle pass. Owns the PlayerBattlePass ProfileStore profile (one session per player, key = UserId): Pass EXP, per-card claims on the three tracks (Scrap free, Flux coins, Void Robux), track ownership per season and processed Void receipt ids. Validates claims and purchases, runs the monthly rollover + auto-grant sweep, and replicates BattlePassStateSync.

Runs in BOTH places. Pass EXP comes only from Pass Mission claims, through Signals.OnQuestRewardGranted (fired by QuestManager). The Void receipt handler is registered only where opts.sellVoid is true (the Lobby), before that place's ReceiptRouter.Start; a Void receipt that reaches another place is retried by Roblox.

Cross-place: STORE_NAME + tostring(UserId) is the same record in every place; ProfileStore session locking serialises the handoff. Level is never stored (BattlePassState.levelFromExp derives it). A track is owned when Owned[track] equals the current season index.
