SpawnHelper

Utility for volume-weighted random spawn point selection, with runtime toggling of named spawn-volume groups.

On startup the module locates (or creates) a Folder named SpawnVolumes in workspace. Each BasePart child of that folder is treated as a spawn volume; its weight is proportional to its world-space volume (Size.X * Size.Y * Size.Z).

A BasePart may carry an optional SpawnGroup string attribute. Parts sharing a value form a togglable group; SetGroupEnabled disables/enables spawning from all volumes in a group at runtime (used by the pirate-ship event to keep junk out of the ship's path). Parts with no SpawnGroup attribute are ungrouped — always active and never affected by toggles.

Init must be called before GetRandomPoint to populate the internal weighted cache. 

local SpawnHelper = require(path.to.SpawnHelper)

SpawnHelper:Init()
SpawnHelper:SetGroupEnabled("Left", false) -- pause spawns in the "Left" group
local point = SpawnHelper.GetRandomPoint()
if point then
	character:PivotTo(CFrame.new(point))
end

Functions​

GetRandomPoint​

</>
SpawnHelper.GetRandomPoint() → Vector3?--

A random world-space position, or nil.

Returns a uniformly random Vector3 point inside one of the enabled spawn volumes. Volume selection is weighted by world-space volume so larger parts are proportionally more likely to be chosen. Volumes in disabled groups are excluded.

Returns nil if Init has not been called or no enabled volumes remain (e.g. every group is disabled).

Init​

</>
SpawnHelper:Init() → ()

Scans workspace.SpawnVolumes and rebuilds the internal weighted cache from all BasePart children, reading each part's optional SpawnGroup attribute. Must be called at least once before GetRandomPoint. Safe to call again if spawn volumes change at runtime — any disabled groups remain disabled.

GetGroups​

</>
SpawnHelper:GetGroups() → {string}--

distinct authored group names.

Returns the distinct SpawnGroup values authored across the spawn volumes. Useful for validation/debug.

IsGroupEnabled​

</>
SpawnHelper:IsGroupEnabled(groupName: string) → boolean

Returns true unless groupName is currently disabled. Unknown or ungrouped names read true (they are never disabled).

SetGroupEnabled​

</>
SpawnHelper:SetGroupEnabled(
groupName: string,
enabled: boolean
) → ()

Enables or disables spawning from every volume whose SpawnGroup attribute equals groupName. Idempotent; rebuilds the active weighted set. Ungrouped volumes are unaffected. warns if no authored volume carries groupName (typo guard) but still records the state so it applies if that group is authored later.
