CrosshairMath

Pure math for the dynamic crosshair, shared by the client (CrosshairController, GunHandler, TrainTurret/ShellWeapon, TurretGuiController) and the server (ShellTurretServer) so the spread cone a shot rolls is the cone the crosshair shows. Angles are degrees, as WeaponValidation.applySpread takes them.

Bloom decays lazily: a Bloom stores its value and the os.clock() it was last written, and current subtracts recovery * elapsed. Nothing is stepped per frame, so the server and the gunner's prediction agree from shot times alone.

CrosshairSource​

}

Payload of Signals.SetCrosshairSource: the image to show and the live cone (degrees). No Cone = floor size.

crossSizePx​

</>

}
) → number

Side (px) of the square cross image for a cone of coneDeg: the cone edge sits at cfg.ConeEdgeRatio of the image half-width, and the radius never drops below cfg.MinRadiusScale * viewportY.

applySource​

</>
CrosshairMath.applySource(
current: CrosshairSource?,
new: CrosshairSource?,
owner: CrosshairSource?
) → CrosshairSource?

The source after a Signals.SetCrosshairSource(new, owner). A clear (new nil) that names its owner only clears while that owner's source is current, so a late clear (a gun unequipped after a turret mount set its source) cannot wipe the newer source. A clear with no owner always clears.
