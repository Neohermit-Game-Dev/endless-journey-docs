PerkState

Pure, side-effect-free perk math shared by the client (button enable) and the server (authorization). Points are DERIVED, never stored: each level-up grants 1 Personal point AND 1 Party point, so a pool's total points equal the player's level; spent = sum of that pool's perk levels; available = total - spent.
