Signals Map

Update this table in the same commit when you add a signal — see also the Add a Signal playbook.

Signals are the in-process event bus (ReplicatedStorage/SharedModules/Signals/init.luau). Prefer signals over direct module coupling for gameplay events and UI intents. All signals defined here are created at module require time and are singletons for the lifetime of the script.

SignalProducerConsumersPurpose
SetTrainStateTrainFuelManager (on running-state flip)JunkServiceSlows junk spawn/speed when braked or stalled. Reused by the fuel system. Signal<boolean>
SetTrainStartedTrainFuelManager (false at init, true on first un-brake)JunkServiceGates whether junk spawns at all; game is frozen until first un-brake. Signal<boolean>
ApplyTierMultiplierPerkEffectsDispatcher (on every party-buff publish, tiers 3–5)JunkServiceDynamic per-tier spawn-rate multiplier (tier: number, multiplier: number). Fired with 1 + JunkTierRarityBonus for rare tiers on every perk state change.
ApplyTypeMultiplier(no producer yet — planned spawn-modifier hook)JunkServiceDynamic per-type spawn-rate multiplier (typeName: string, multiplier: number).
TryClaimJunkGrabHookJunkControllerFire claim request (id: number, hitPos: Vector3); JunkController invokes ReqJunkClaim.
TryClaimJunkBatchGrabHook (Net Cast perk, capacity ≥ 2)JunkControllerFire batch claim request ({number}) (junk ids); JunkController invokes Packets.ReqJunkClaimBatch.
TryFinalizeJunkGrabHookJunkControllerFire finalize request (id: number) after retraction completes; JunkController invokes ReqJunkFinalize.

OnShootingCameraToggledCameraController (fires when aim mode toggles)(internal to CameraController — maxDistanceForMode() reads aimMode directly in the same script that fires this signal; no external consumer today)Broadcast aim-camera engage/disengage Signal<boolean>. Kept as a public signal since a future external system (e.g. a HUD reticle or a weapon-specific FOV tween) may still want to react to the mode switch without polling CameraController.
RequestShootingCameraGrabHook (equip/unequip), WeaponController (weapon equip/unequip), PlacementClient (build mode entry)CameraController (toggles aim mode)Programmatic aim-camera control Signal<boolean?>.
RequestMouseIconWorkbenchGuiController (open/close, PC only)CameraController (cursor reveal + frees MouseBehavior)Show/free or hide/lock the mouse cursor Signal<boolean>. While true (and not aiming), the camera sets MouseBehavior = Default so the cursor is clickable; false restores LockCenter.

OnResearchLevelUpResearchService (server, when the active job's elapsed >= duration)ResearchEffectsDispatcher (recomputes ResearchBuffs + publishes ResearchUnlocked)Server-side node level-up Signal<string, number> (nodeId, newLevel).
OnResearchStateChangedResearchService (server, after every broadcast() — enqueue/cancel/refuel/tick)(reserved for optional consumers, e.g. a future HUD)Server-side notification that Research Bench state changed. Signal(), no payload.
OnPlayerLevelUpXPManager (on level increase in AddXP)PerkManagerServer-side: notify that a player's level increased so PerkManager can re-replicate available points. Signal<Player, number> (player, newLevel).
OnPerkStateChangedPerkManager (after every AllocatePoint or Respec)PerkEffectsDispatcherServer-side: notify that a player's perk allocation changed so PerkEffectsDispatcher republishes buff folders. Signal<Player> (player).
OnTrainShieldChangedTrainShieldController (on TrainShieldSync; writes TrainStateCache before firing)(none currently — see note)Shield state broadcast (currentShield: number, maxShield: number). Signal<number, number>. TrainShieldGuiController no longer subscribes; it reads TrainStateCache (ShieldFraction()) instead, so a controller that connects late still recovers the snapshot — see Join-Sync Snapshot Handshake. This signal currently has zero subscribers in src/; it is kept deliberately as the push-side extension seam for a future shield UI (the cache is the poll-side path today) — do not mistake it for live plumbing, and do not delete it without the project owner's sign-off.
OnTrainGameOverTrainGameOver (server, on the first Trigger call per round)(events system)Server-side round-end notification (reasonCode: number) — a TrainGameOverReason value (NONE/FUEL_DEPLETED/FUEL_DESTROYED_BY_ATTACK). Fires exactly once per round, from either the natural fuel stall-out or the immediate combat fuel-kill path. Signal.Signal<number>
OnEnemySpawnedEnemySpawner (server, after each successful clone+pivot)(reserved — future spawn-telegraph controller)Fires after every enemy is placed. (position: Vector3, archetypeName: string). A client controller can subscribe to play a spawn-telegraph SFX/VFX at the location. Signal<Vector3, string>
OnItemCraftedWorkbenchGuiController (client, after server confirms a successful craft)(reserved — no current consumer)Client-local notification that a recipe was crafted. (recipeId: string). Reserved for future HUD feedback (e.g. an item-received toast or inventory flash). Signal<string>
RequestWorkbenchCategory(no producer yet — future category dropdown)WorkbenchGuiController (re-filters the recipe grid)Client request to switch the active recipe category filter. (category: string) — one of WorkbenchConfig.Categories values. Until the dropdown is built nothing fires this; the grid defaults to WorkbenchConfig.DEFAULT_CATEGORY ("all"). Signal<string>
OnGameEventStartedEventOrchestrator (server, when a channel activates a handler)(none yet; reserved for music/analytics)Fires when an in-game event begins. (eventId: string). Signal<string>
OnGameEventEndedEventOrchestrator (server, when a handler's finish() resolves)(none yet; reserved for music/analytics)Fires when an in-game event ends. (eventId: string). Signal<string>
OnSettingChangedSettingsClient (after every applied change — join-sync via SyncSettings AND manual Set)(settings GUI — not yet built), any reactive consumerUser-preference change (key: string, value: any). Fired once per key after SettingsAppliers.Apply runs, so consumers always see the already-applied value. Signal<string, any>
OnJunkCollectedJunkService (server, on junk award — once per successful finalized grab)QuestSourcesLoaderServer-side: a player finalized a junk grab (collector: Player, junkId: number). Translated into a JunkCollected quest-progress report via QuestManager.ReportProgress. Signal<Player, number>
LeaveToLobbyRequested(no producer yet — reserved for a future menu "Leave to lobby" button)SessionClientDeliberate leave-to-lobby intent. No payload. SessionClient forwards it to the server as Packets.ReqLeaveToLobby, marking the departure clean so SessionCoordinator skips the rejoin grace hold. See Party Lock + Mid-Run Rejoin. Signal()
OnQuestRewardGrantedQuestManager (server, from the shared grantReward path — manual ReqClaimQuest claim AND the rollover auto-grant sweep)BattlePassManagerServer-side: a quest reward was granted (player: Player, reward: Quest.Reward). BattlePassManager reads the optional reward.BPExp off the payload to accrue Battle Pass EXP. Signal<Player, any>
OnBattlePassItemGrantedBattlePassManager (server, when an Item-type tier reward with a non-empty ItemId is granted)(no consumer this cycle — reserved for a future inventory/accessory system)Server-side: a battle pass Item reward was granted (player: Player, itemId: string). See Battle Pass — Item seam. Signal<Player, string>
OnBattlePassLevelUpBattlePassManager (server, in AddExp, when the derived level rises)(no consumer this cycle — reserved for a future FX/toast seam)Server-side: a player's battle pass level increased (player: Player, newLevel: number). See Battle Pass. Signal<Player, number>
OnJumpPhaseChangedJumpDriveManager (server, on every phase transition)JunkService (halts/restores spawning), EventOrchestrator (SetJumpPaused — suspends odometer/channels, force-finishes any Active handler), TrainFuelManager (SetJumpFreeze — pins drain to 0), TrainShieldManager (SetJumpFreeze — ApplyDamage early-returns), QuestSourcesLoader (reports QuestConfig.Metrics.BiomeJumps on the arrival edge)Server-side: the jump drive's phase changed (phase: string), a JumpDriveConfig.Phase value.
