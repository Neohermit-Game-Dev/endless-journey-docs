LeviathanPlanner

Builds the Leviathan's fight moves as segments (see LeviathanPath). Ported from the approved fight-cycle preview (tools/studio-previews/leviathan-prowl-preview.luau, 2026-11-07).

The head swims like an animal: constant speed, a capped turn rate (turn radius >= SteerRadius), steering toward a wanted direction. A waypoint is dropped every WaypointSpacing studs; the spline through them follows the swim, so every turn stays wide by construction. Every move starts from the current body (state.nodes) and keeps the head's speed.

All builders return a segment without Start (the caller sets it) and with Cut: the move time when the next move takes over.

A FromCurrent config move (e.g. Slam) from the current body: the body leads in, then Lead (head space: +X = its flattened heading, -Z = out away from the train), then Path (slam space: the train centre, same axes). Also used by LeviathanAnimator.Play for the preview tools.

The approved laser, led in from the current body: dives out and down to a staging point well back along the laser's rise, follows that line in, then the approved path and timing follow (shifted by the lead-in time). trainLength (studs along X) sets the sweep.

Scream​

</>
LeviathanPlanner.Scream(
state: State,
origin: CFrame
) → Segment

Rears up with the jaw wide and roars (swarm call). From deep below (after the laser) it first climbs back up beside the train.

Defeat​

</>
LeviathanPlanner.Defeat(
state: State,
origin: CFrame
) → Segment

Drive-off (HP 0): flinches and roars nearly stopped (Drift), then turns wide away from the train and pitches down (Turn), with a short straight dive after it; the Defeat clip plays on top. From deep below it climbs back up first and the reaction keys start after the climb. Cut = when the turn is done (RiftOut takes over).
