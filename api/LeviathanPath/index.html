LeviathanPath

Pure path maths for the Leviathan, shared by the server (hitboxes, hit timing) and the clients (LeviathanAnimator). A move is sent as a segment: world-space head path points, timing keys and a server start time. Server and clients run the same maths on it, so the hitboxes and the picture agree. 

local path = LeviathanPath.buildPath(segment.Points)
local m = LeviathanPath.resolve(segment)
local nodes = LeviathanPath.nodesAt(m, path, restArc, workspace:GetServerTimeNow() - segment.Start)

interface Segment {
Move: string--

style entry in LeviathanAnimConfig.Moves (Wave, Wings, Jaw, Aim, Laser, Events, Pitch, Shake, ShakeHz, Glow)

Points: {Vector3}--

world-space head path control points

Keys: {{number}}--

{ seconds, pointIndex }

Start: number--

workspace:GetServerTimeNow() time of key time 0

StartSlope: number?--

point index per second at t = 0 (keeps the head's speed)

Sweep: {Vector3}?--

laser target from / to (world)

Rifts: {Rift}?
}

Any style field (Wave, Wings, Jaw, Aim, Laser, Events, Pitch, Shake, ShakeHz, Glow) set on the segment overrides the style entry.

Monotone cubic (Fritsch-Carlson) through { time, value } keys: no overshoot, no stop at interior keys unless the values hold. Starts at rest unless startSlope (value per second) is given; ends at rest.

nodesAt​

) → (

Spine node world positions (tail -> head) at move time t, swim wave included. Also returns the node frames and the head's arc length. m is a resolved segment (or any table with Keys, StartSlope, Wave). headUp (default world up) is the head frame's up; the animator carries it frame to frame.

prepare​

</>
LeviathanPath.prepare(segment: Segment) → (
Segment,
Path
)

Resolves a segment, builds its path and its head-up track (cached per segment table). The head's up is carried along the move from world up, leaning back to world up a little every 1/60 s: a head pointing straight down never flips the body, and server and clients get the same frames at any move time (no frame-to-frame state). Returns the resolved segment (with HeadUps) and the path.

duration​

</>

Move length: the last key time, or a later Aim key (jaw clips run past the end).

interface Rift {
pos: Vector3--

rift centre (world)

normal: Vector3--

unit, points to the visible side

radius: number?--

studs (default 500)

}

A point behind a rift (on the hidden side of its plane, within the rift disc) is projected onto the rift's centre plane, so the body never shows past the black orb. Points elsewhere come back unchanged.
