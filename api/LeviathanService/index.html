LeviathanService

This item only works when running on the server. Server

The Leviathan boss fight. When the threat timer runs out (Signals.OnThreatArrived) it rifts in and runs the fight cycle chosen by LeviathanBrain. Every move is a segment built by LeviathanPlanner, broadcast once (Packets.LeviathanSegment) and played by every client on server time; the server poses the hitboxes (LeviathanBody) with the same maths and deals the hits at the move's event times.

It cannot die: at 0 HP it screams and leaves, everyone gets the drive-off reward and the threat timer restarts. A jump makes it leave with no reward. Each visit in a run is stronger. See docs/systems/leviathan.md.
