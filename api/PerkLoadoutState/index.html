PerkLoadoutState

Pure shop perk rules, shared by the server (authority) and the client (button states). Functions take the saved inventory table and now (os.time() seconds); the mutating helpers change only the table they are given.

  • Slots: Personal 3 (+1 at Lv 10, 20, 30); Party 1 (+1 at Lv 30). Equip appends; unequip removes one entry and later slots move up (lists stay dense).
  • Same perk once: a pool holds each perk id at most once. Perks of one Family stack (Family is a label only).
  • Expiring clock: the first equip moves Banked into Expires = now + Banked. Time added while the clock runs extends Expires; time added while it is stopped goes to Banked. Unequip never pauses the clock.
  • prune drops ended clocks and every loadout entry that is unknown, hidden, in the wrong pool or no longer owned.
  • beginRun fixes the run's loadout (ActiveRun) and uses one copy of each equipped consumable, once per run id.
