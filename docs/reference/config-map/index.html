Config Map

Update this table in the same commit when you add a config module — see also the relevant system playbook linked in each row.

All tuning lives in config modules under src/ReplicatedStorage/SharedModules/Configs/. Prefer config changes over code changes when adjusting gameplay feel. The modules are accessible from both client and server.

ConfigPrimary Controls
PlacementConfigGhost update frequency, ghost visuals, grid texture, icon assets. See Placement.
JunkConfigSpawn rate, server/client caps, tier/type weights, speed/direction, pity threshold, speed-ramp duration. See Junk Flow playbook.
StaminaConfigMax stamina, drain/regen rates, regen delay, sprint speed multiplier, FOV delta, buff defaults. See Tune Stamina playbook.
HealthConfigMax health, regen rate, regen delay.
GrabHookConfigBeam appearance, projectile behavior, max distance, grapple-loop fade timings. (Sound assets live in SoundConfig.)
CameraConfigThird-person + aim offsets, offset-spring tuning (Omega/Zeta), per-mode look angle (ShootingLookAngle/ThirdPersonLookAngle), reticle config, CameraBoom zoom range, raycast buffer, smoothing.
NotificationConfigToast types/colors/imageIds, per-type SFX names, device sizing, animation timing, MaxConcurrent cap, ExecutedFunctionTimeout.
ShredderConfigInteract distance, hold duration range, anti-exploit tolerances, arc animation params, auto-collect delay, CollectionService tag, folder names.
JunkToolConfigTool textures keyed by junk name.
ProximityPickupConfigDetection radius, float animation duration, hover/spin params, drop-landing: SETTLED_VELOCITY_THRESHOLD, DROP_POLL_INTERVAL, DROP_LANDING_TIMEOUT. DroppableSurface CollectionService tag controls which surfaces dropped items land on.
TrainConfigMax fuel, running/stopped drain rates, game-over delay, proximity tolerance, engine/lever CollectionService tags + prompt part names, brake action text, per-tier fuel recharge values. Shield: BASE_SHIELD, SHIELD_REGEN_ENABLED/SHIELD_REGEN_PER_SEC, SHIELD_CONSOLE_TAG, SHIELD_PROMPT_PART_NAME, CORE_TAG, ShieldRecharge tier table, FUEL_DAMAGE_FACTOR (0.05 — shield-down bleed-through: fuel lost = attackDamage * FUEL_DAMAGE_FACTOR, routed TrainShieldManager.ApplyDamage → TrainFuelManager.ApplyFuelDamage). Both client and server resolve prompt parts recursively via PromptResolver. See Train Fuel and Train Shield.
TrainGameOverReason (enum module, not a tuning config)Frozen numeric enum identifying how a round ended: NONE = 0, FUEL_DEPLETED = 1 (natural fuel-out, after TrainConfig.GAME_OVER_DELAY), FUEL_DESTROYED_BY_ATTACK = 2 (combat fuel-kill, immediate). Lives in ReplicatedStorage/SharedModules/TrainGameOverReason.luau. Stored by TrainGameOver.Trigger/GetReason and broadcast via Signals.OnTrainGameOver. See Train Fuel — Game-over reasons.
SoundConfigAll game audio: per-name SFX defs (id/volume/pitch/group/replicate/debounce), BGM playlist defs, ambience bed defs, per-bus group volumes. Helpers: GetReplicatedIds() (server relay allowlist), GetPreloadIds(). Consumed by SoundManager.
SettingsConfigUser-preferences definitions registry (pure data) — single source of truth for the settings system. Definitions table keyed by setting name: per-key type/default/min/max/step/options, plus category/label/order for GUI grouping/display. VolumeBusByKey maps volume setting keys to their SoundConfig bus. STORE_NAME ("PlayerSettings") for ProfileStore. GetDefaults() returns a fresh key→default map. See Settings (User Preferences).
WeaponConfigPer-weapon registry keyed by Tool name: category, damage + DamageType, melee combo steps (Recovery/ChainWindow/finisher), gun fire-rate (RPM/Automatic)/ammo (MagazineSize/AmmoType/ReloadTime)/Spread/MaxDistance/HeadshotMultiplier, projectile + throwable AOE (AOERadius/AOEDamage), FuseTime/Detonation/MaxActive, and per-weapon SoundConfig keys. ReserveMax and CarryCount have been removed — guns use AmmoType to reference a pool in AmmoConfig; throwable count is inferred from Backpack Tool instances. See Weapons system.
AmmoConfigAmmo type definitions and gun→type mapping. AmmoTypes table: { Light = {DisplayName, Capacity=300, Starting=0}, Heavy = {DisplayName, Capacity=60, Starting=0}, Rocket = {DisplayName, Capacity=12, Starting=0} }. All Starting values are 0 — players get no free reserve ammo; reserve is crafted (a freshly crafted weapon still spawns with one full magazine). WeaponAmmo map: Pistol/SMG/AR → Light, SR → Heavy, RocketLauncher → Rocket. Pool is session-only (no DataStore); cleared on leave. AmmoManager.EnsureStarting seeds each type to its Starting amount on the player's first spawn only; the pool then persists across death for the rest of the session (dying never refills reserve ammo). See Weapons system.
ResearchConfigBench tag + interaction/refuel prompt part names, interaction distances, queue/fuel constants (QUEUE_MAX, FUEL_CAP, FUEL_BURN_RATE, ACTIVE_REFUND_FRACTION, EnergyFuelValue, TICK_INTERVAL, HEARTBEAT_BROADCAST_INTERVAL), refund-arc tuning (ported from the old TechTreeConfig: duration, height, scatter, eject delay/caps, auto-collect delay), trajectory/materials folder names, and the Nodes table (per-level Cost/Duration, Prereq/PrereqLevel, MaxLevel, Effect). See Research Bench system and Tune Research Bench playbook.
PerkConfig12 perk declarations (Personal: Vitality/Regeneration/Quick Reel/Power/Fortune/Armor/Net Cast; Party: Salvage Luck/Efficiency/Thrift/Shield Capacity/Heavy Ordnance). Per-perk PerLevel, MaxLevel, BuffKey, display strings, and per-perk UnlockCost (one-time coin cost to unlock; 0/nil = free starter) / UnlockLevel (min player level to unlock; 0/nil = none). STORE_NAME for ProfileStore key. See Perks system, Tune Perks playbook, and Tune Perk Unlocks playbook.
ArmorConfigCrafted-armor tier table (Tiers[tier] = { BaseReduction, DisplayName }), MaxReductionCap (0.75 hard cap enforced at the HealthManager sink), STORE_NAME (PlayerArmor). Consumed by ArmorManager (publishes ArmorState/<UserId>.ArmorBaseReduction) and HealthManager (cap).
CannonConfigCannon ballistics, mount range, overheat params, part/sound keys, EnemyShip tag. See Cannon system.
EnemySpawnerConfigGLOBAL_MAX_ENEMIES (hard perf cap), DEFAULT_POINT_RADIUS, WeightFalloff (cumulative-inverse exponent), Verification.* (MaxGroundDrop, HeadroomSize, MinEnemySpacing, MaxRetries), Archetypes (per-archetype Model name, Health, WalkSpeed, DefaultRadius, Faction). Auto-validates archetype model names against ServerStorage.EnemyAssets at load. See Enemy Spawner.
EnemyCombatConfigPer-archetype enemy combat Profiles table, keyed by the same archetype name used in EnemySpawnerConfig.Archetypes (an archetype with no profile here stays unarmed/passive). Per-profile Class (Ranged/Melee), Weapon (FX key), Damage, ranged FireMode/ProjectileSpeed/Spread/Range/CloseDistance/MuzzleOffset, no-ammo burst rhythm (ShotInterval, BurstMin/Max, BurstCooldownMin/Max, sniper Telegraph), lob-only AOERadius/FuseTime, melee-only HitboxSize/AttackCooldownMin/Max. GetProfile/FindByWeapon lookups. See Enemy Combat.
WorkbenchConfigSTATION_TAG ("Workbench" — shared with the Shredder, which lives on the same station Model), INTERACT_DISTANCE (12 studs), INTERACT_DISTANCE_TOLERANCE (5 studs), PROMPT_PART_NAME ("CraftPromptPart"), CRAFT_COOLDOWN (0.5 s per-player gate), MATERIALS_FOLDER ("CraftingMaterials" in ReplicatedStorage — shared with Shredder/Research Bench), WEAPON_TEMPLATES_FOLDER ("WeaponTemplates" in ServerStorage). Category knobs: DEFAULT_CATEGORY ("all"), Categories ({all,ammo,weapons,armor,misc}), RecipeCategories ({ammo,weapons,armor,misc}), CategoryLabels (display strings). Sounds.CraftSuccess / Sounds.CraftFail (SoundConfig keys; "" = silent). Recipes table: { [recipeId]: Recipe } where each Recipe has Category, DisplayName, Description, Tier (1–5 flavor badge only), Icon, Cost { Wood?, Metal? }, RequiresNode (Research Bench nodeId gate or nil), and Output ({ Kind="Weapon", ToolName } | { Kind="Armor", Tier } | { Kind="Placeable", PlaceableName }). GUI is fixed to two material rows so Cost is limited to Wood/Metal. See Workbench Crafting.
EventConfigCruiseSpeed (virtual odometer studs/sec while running), TickInterval (odometer loop cadence). Channels table (Encounter): per-channel RollInterval, PostEventDelay, PityRolls, StartGrace, MaxActiveDistance, and a weighted Table of { Event, Weight } / { Nothing = true, Weight } roll entries. Events table: per-event parameters keyed by handler Id (e.g. PirateAttack.Group/.Wave, Outpost.Window/.SideAttribute). See Events Orchestrator.
DisruptionConfigLOBBY_PLACE_ID (teleport target; 0 skips teleport), NOTICE_SECONDS, FLUSH_TIMEOUT_SECONDS, MAX_DRAIN_SECONDS, TELEPORT_RETRIES, MESSAGING_TOPIC (cross-server fan-out), ADMIN_USER_IDS, ADMIN_COMMAND (manual maintenance chat trigger), DEFAULT_MESSAGE/REASON_MESSAGES, NOTIF_TYPE. See Disruption / Maintenance.
QuestConfigSTORE_NAME (ProfileStore key), ResetTimezoneOffset (fixed seconds-from-UTC the daily/weekly "midnight" is measured in; pre-launch default US Eastern -5*3600, no DST tracking, 0 = pure UTC), DailyResetOffset/WeeklyResetOffset (period boundary, seconds — derived from ResetTimezoneOffset), ROLLOVER_CHECK_SECONDS (live rollover tick cadence), DISTANCE_TICK_SECONDS/DISTANCE_PER_TICK (train-running distance source cadence/amount), ENEMY_TAG (CollectionService tag for the kill source), Metrics (fixed metric-key registry: EnemyKills, DistanceTravelled, JunkCollected), Counts (Personal/Party quests per Daily/Weekly period), and the Quests pool (Scope/Category/Metric/Target/Reward{Coins,Exp,BPExp?}/DisplayName/Description/Icon). Scope includes a non-rotating "Season" value (whole set active all month, keyed to BattlePassState.seasonIndex) whose quests feed the battle pass via the optional Reward.BPExp. See Quests system and Tune Quests playbook.
BattlePassConfigSTORE_NAME (ProfileStore key), SUBSCRIPTION_ID (Roblox subscription id gating the Premium row; "" disables premium and skips the subscription APIs entirely), ResetTimezoneOffset (fixed seconds-from-UTC the calendar-month season boundary is measured in; mirrors QuestConfig.ResetTimezoneOffset, no DST tracking), MAX_LEVEL (top tier, 60), ExpPerLevel (BP EXP required per level — flat number or { [level]: number } table), ROLLOVER_CHECK_SECONDS (live season-rollover + premium-refresh tick cadence), Tiers[level] = { Free: Reward?, Premium: Reward? } (base reward per tier per row; Reward is {Type="Coins",Amount} or {Type="Item",ItemId}), and SeasonOverrides[seasonIndex][level] (sparse per-season tier reward shadowing). See Battle Pass system and Tune Battle Pass playbook.
JumpDriveConfigStation/interaction: BENCH_TAG, JUMP_PROMPT_PART_NAME, DEPOSIT_PROMPT_PART_NAME, PROXIMITY_TOLERANCE, WORMHOLE_ANCHOR_TAG. Charge: MAX_CHARGE, EnergyChargeValue (tier → charge, same shape as ResearchConfig.EnergyFuelValue). Phases: Phase enum, IsJumpActive(phase), VoteDuration, EngulfDuration, MinWormholeHold, MaxWormholeHold, ExitDuration. Biomes: BIOME_ATTRIBUTE (workspace attribute name), Biomes (destination list). Rewards: ArrivalReward (Coins/Xp/BPExp, flat). VFX: VFX_FOLDER, WORMHOLE_MODEL, LIGHTSPEED_MODEL, WormholeStartScale, PostFx. See Jump Drive.
SessionConfigParty-lock + mid-run rejoin tunables, shared verbatim with the separate lobby project: GRACE_WINDOW_SECONDS (120 — how long a dropped player's slot + cached health/ammo/Tools are held for rejoin), SESSION_HEARTBEAT_SECONDS (30 — MemoryStore TTL refresh cadence), ENTRY_TTL_SECONDS (90, 3x heartbeat — self-expiry if a server dies unobserved), GAMEPLAY_PLACE_ID (this place's PlaceId; 0 = unset), ROSTER_MAP_NAME/SESSION_MAP_NAME (MemoryStore hash-map names), BYPASS_GUARD_IN_STUDIO (authorize everyone in Studio; default true). See Party Lock + Mid-Run Rejoin.

Runtime buff folders​

These are not config modules but runtime ReplicatedStorage folders written by dispatchers and read by gameplay systems. Listed here because their writer/reader contracts are as important to maintain as static config.

Folder / AttributeWriterReader(s)Notes
ReplicatedStorage/ResearchBuffs.FuelEfficiencyResearchEffectsDispatcher (recomputeBuffs, FuelEfficiency handler)TrainFuelManagerDrain multiplier; product of DrainPerLevel ^ level across all FuelEfficiency-effect nodes (recomputed from scratch on every level-up). Defaults to 1.0 (no effect) until Fuel_T1 reaches level 1. Stacks multiplicatively with PartyPerkBuffs.FuelEfficiencyBonus — see Research Bench.
ReplicatedStorage/ResearchBuffs.MaxHPResearchEffectsDispatcher (recomputeBuffs, StatBuff handler)TrainShieldManager.recomputeMaxNumeric sum of PerLevel * level across all StatBuff-effect nodes sharing the MaxHP key (Durability_T1: +50/level, up to MaxLevel = 3). Read as additive shield capacity: maxShield = (BASE_SHIELD + MaxHP) * (1 + TrainShieldBonus).
ReplicatedStorage/ResearchUnlocked/<nodeId>ResearchEffectsDispatcher (publishUnlocked)WorkbenchService (server gate), WorkbenchGuiController (client greying)BoolValue (Value = true) per node at level ≥ 1, including recipe nodes (Effect = nil). Unforgeable — server-written only. See Research Bench and Workbench Crafting.
ReplicatedStorage/PerkBuffs/<UserId>.DamageBonusPerkEffectsDispatcherWeaponServer (scaledDamage helper, all 5 player-attack sites, applied after headshot multiplier)Personal perk; read server-side via FindFirstChild(tostring(player.UserId)).
ReplicatedStorage/PerkBuffs/<UserId>.CoinGainBonusPerkEffectsDispatcherCoinManager.AddCoinsPersonal perk; applied as math.max(1, math.floor(amount * (1 + bonus))) — 1-coin floor.
ReplicatedStorage/PartyPerkBuffs.FuelEfficiencyBonusPerkEffectsDispatcherTrainFuelManagerParty perk (server-max resolution); combined with ResearchBuffs.FuelEfficiency multiplicatively: effectiveRate = baseRate × max(0.1, ResearchBuffs.FuelEfficiency × max(0.1, 1 − FuelEfficiencyBonus)).
ReplicatedStorage/PartyPerkBuffs.TrainShieldBonusPerkEffectsDispatcherTrainShieldManager.recomputeMaxParty perk (server-max resolution); 0.05 * maxLevel. Combined with ResearchBuffs.MaxHP multiplicatively: maxShield = (BASE_SHIELD + MaxHP) * (1 + TrainShieldBonus).
ReplicatedStorage/ArmorState/<UserId>.ArmorBaseReductionArmorManagerHealthManager (applyDamageInternal)Per-player crafted-armor base reduction (fraction); combined with PerkBuffs/<UserId>.ArmorEfficiency at the damage sink: clamp(ArmorBaseReduction * (1 + ArmorEfficiency), 0, ArmorConfig.MaxReductionCap). Defaults to 0 (tier 0 / unarmored).
