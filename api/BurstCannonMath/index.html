BurstCannonMath

Pure math shared by the server (BurstCannonServer) and the client (BurstCannonController) so both sides agree on where the barrels point and where a shell leaves the muzzle. Angles are radians. Yaw is positive to the left, pitch is positive up, barrels look along the joint frame's -Z.

Cadence after a shot. inBurst is the shots already fired in this burst (0..BurstSize-1); returns the next fire time and the new count (0 = the burst ended, so the next shot waits BurstPause). rate scales the cadence (1 manned, AutoLoaderRate unmanned). Never banks shots while idle.
