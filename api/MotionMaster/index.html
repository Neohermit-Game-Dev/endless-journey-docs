MotionMaster

The project's animation library. Use instead of TweenService for all client-side animations. Supports 15+ motion models (classic easing, Bézier, spline, spring ODE, kinematics), arc-length reparameterization, time-warp, and CFrame quaternion SLERP.

MotionMaster.Create returns a TweenObject with full lifecycle control: :Play, :Pause, :Resume, :Cancel, :Reverse, :Scrub, :Destroy.

MotionMaster.Spring returns a SpringDriver — a live, frame-rate- independent spring that follows a moving target with exact ODE integration.

MotionMaster.SplineMove(
target: BasePart,--

the part whose Position will be driven

controlPoints: {BasePart | Vector3},--

ordered list of control points (minimum 2)

config: {
Duration: number?,
Model: (string | (number) → number)?,

ArcSamples: number?,

}?--

animation options

) → TweenObject--

a stopped TweenObject ready for playback

Animate a BasePart along an arc-length-reparameterized Catmull-Rom spline defined by controlPoints. Each control point may be a BasePart (position is extracted) or a Vector3. Requires at least 2 control points. ConstantSpeed defaults to true.

Returns a TweenObject; call :Play() to start movement.

Animate a Model to a target CFrame using :PivotTo(), which preserves the relative offsets of all parts inside the model. Internally creates a proxy that routes CFrame writes through :PivotTo() so all standard MotionMaster.Create config fields apply.

Returns a TweenObject; call :Play() to start the animation.
