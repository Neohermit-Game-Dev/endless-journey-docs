ArmIK

Analytic two-bone arm IK for R15 rigs (players: AnimationConstraint joints; pirates: Motor6D joints). Pins a hand's end effector (grip, hand space) to a target in UpperTorso space and writes the shoulder, elbow and wrist .Transform. Solved from joint frames only (no part CFrames), so it has no frame lag: call it in RunService.PreSimulation, after the animation step, with the target computed in the same frame. The elbow bends in the plane that holds the shoulder, the target and the pole (a point in UpperTorso space). R15 elbows hinge about local +X and bend forward.
