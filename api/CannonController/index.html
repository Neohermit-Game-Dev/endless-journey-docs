CannonController

This item only works when running on the client. Client

Drives the manned-cannon experience for the local player: a ProximityPrompt on each placed cannon to mount; while mounted, locks movement, shows a ballistic arc preview, and fires on input via ReqFireCannon (server is authoritative). Renders CannonFired (muzzle flash + barrel snap + fire sound) and the cannon explosion sound for all clients. No authoritative state lives here.
