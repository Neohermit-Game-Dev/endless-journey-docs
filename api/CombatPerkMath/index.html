CombatPerkMath

This item only works when running on the server. Server

Pure math for the Perk Rework part 5 combat perks (Batch A). No services and no state: callers own the tables they pass in. Studio-only self-check at the bottom.

Types​

LifestealBucket​

</>
type LifestealBucket = {
level: number,
at: number
}

One player's Vampire Rounds heal budget: level HP left, at = the clock of the last take.

Mark​

</>
type Mark = {
expires: number,
bonus: number
}

A Weak Spot mark on one enemy: player damage to it is ×(1 + bonus) until expires.

Functions​

lifestealTake​

</>
CombatPerkMath.lifestealTake(
bucket: LifestealBucket,
want: number,
now: number,
capPerSecond: number
) → number

Takes up to want HP from bucket at clock now and returns what may be healed. The bucket refills at capPerSecond and holds at most one second's worth, so healing never passes capPerSecond per second over time.

dawnSave​

</>
CombatPerkMath.dawnSave(
health: number,
damage: number,
maxHealth: number,
ready: boolean,
fraction: number
) → number?

Second Dawn: the health left after a hit of damage (same scale as health) when that hit would kill and the save is ready: fraction of maxHealth. nil when the hit does not kill, the save is recharging, or the player is dead.

accuracyPenalty​

</>
CombatPerkMath.accuracyPenalty(
party: number,
personal: number,
cap: number
) → number

Pirate spread penalty on one target: Fuzzy Hologram (party) + Void Cloak (personal, the target's own), at most cap.

streakBonus​

</>
CombatPerkMath.streakBonus(
kills: number,
perKill: number,
cap: number,
lastKillAt: number,
now: number,
seconds: number
) → number

Battle Rhythm: kills × perKill, at most cap, while now is within seconds of lastKillAt; else 0.

critMultiplier​

</>
CombatPerkMath.critMultiplier(
rTriple: number,
tripleChance: number,
rDouble: number,
critChance: number
) → number

The crit multiplier of one hit from two rolls in [0, 1): Star Shot (×3 when rTriple < tripleChance) first, else Lucky Shot (×2 when rDouble < critChance).

refillMag​

</>
CombatPerkMath.refillMag(
mag: number,
size: number,
fraction: number
) → number

Scavenger Rounds: mag plus fraction of size (rounded up), at most size.

markBonus​

</>
CombatPerkMath.markBonus(
mark: Mark?,
now: number
) → number

The damage bonus mark gives at clock now (0 without a mark or after it ends).

finisherExtra​

</>
CombatPerkMath.finisherExtra(
health: number,
maxHealth: number,
bonus: number,
fraction: number
) → number

Finishing Touch: bonus when the target is below fraction of its max health, else 0.

lowArcDirection​

</>
CombatPerkMath.lowArcDirection(
from: Vector3,
to: Vector3,
speed: number,
gravity: number
) → Vector3?

Smart Cannon aim: the unit launch direction of the low arc that carries a shell fired at speed from from to to under downward gravity (a positive number), or nil when to is out of reach.
