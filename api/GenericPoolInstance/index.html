GenericPoolInstance

A reusable Roblox PVInstance (Part or Model) object pool that manages creation, retrieval, and recycling of instances. Instances are stored in a hidden Folder at math.huge when idle, then teleported to their requested CFrame via a batched BulkMoveTo call on the next PreRender step.

Pools can be registered in a shared registry via MakeGlobal so that multiple scripts can access the same pool by name. 

local GenericPoolInstance = require(path.to.GenericPoolInstance)

local pool = GenericPoolInstance.new(workspace.MyTemplate, 20, 100, 10)
local part = pool:RetrieveObject(CFrame.new(0, 5, 0))
-- ... use part ...
pool:InsertObject(part)

Creates a new GenericPoolInstance pool.

The objectTemplate is cloned immediately; the original is never re-parented. If initialSize > 0 the pool is pre-filled with clones and the optional insertFunction is called on each one.

Clear​

</>
GenericPoolInstance:Clear() → GenericPoolInstance--

Returns self for chaining.

Destroys all instances currently held in the pool and empties the pool array. The pool itself remains usable; it will auto-expand on the next RetrieveObject call.

Destroy​

</>
GenericPoolInstance:Destroy() → ()

Destroys all pooled instances, removes the internal storage folder, and de-registers the pool from the global registry. The pool table is wiped and the metatable cleared; the reference should be discarded afterwards.
